# 深潮（工作名）

以**理智**作为第二资源的克苏鲁卡牌肉鸽（类杀戮尖塔）：**离疯狂越近，你越强，也越看不清真相。**

- 理智跌到 4 或以下时进入**癫狂**：双面牌翻到更强、带副作用的癫狂面，敌人意图只显示类型、不显示数值
- 理智归 0 会**崩溃**：失去生命，一张「疯语」诅咒永久加入牌组
- 同一条理智规则衍生出三个流派：**守夜**（维持满理智）、**堕落**（主动跌入癫狂）、**传染**（把恐惧施加给敌人）

引擎为 Unity 6（C#），当前目标是可玩 Demo：1 个角色、1 幕、40 张卡。详见 [策划案](策划/README.md)。

## 目录结构

```
├─ 策划/        策划案：核心机制、战斗、卡牌、敌人、遗物与事件、地图、数值、技术方案、开发计划

└─ Tools/       在 Unity 外编译内核：单元测试 + 控制台对战 / 批量模拟
```

## 快速开始

需要 [.NET 10 SDK](https://dotnet.microsoft.com/download)，不需要安装 Unity。以下命令都在 `Tools/` 目录下执行。

```bash
cd Tools
dotnet test
```

手动对战（`--deck`：A 守夜 / B 堕落 / C 混合；`--enc`：1 教团侍僧 / 2 侍僧 + 呓语者 / 3 失魂镇民 ×2）：

```bash
dotnet run --project Deeptide.Sim -- play --deck C --enc 2 --seed 42
```

批量模拟，统计每个牌组 × 遭遇组合的胜率、掉血、崩溃次数和癫狂回合占比：

```bash
dotnet run --project Deeptide.Sim -- batch --n 500
```

更多用法见 [Tools/README.md](Tools/README.md)。
