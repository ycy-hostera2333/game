# 02 战斗系统

## 1. 基础资源

| 资源 | 默认值 | 规则 |
|---|---|---|
| 生命 | 最大 70 | 跨战斗保留，归零即本局失败 |
| 能量 | 每回合 3 | 回合开始重置，不累积 |
| 抽牌 | 每回合 5 | 抽牌堆空时把弃牌堆洗回去 |
| 手牌上限 | 10 | 超出的抽牌直接进弃牌堆 |
| 格挡 | — | 玩家回合开始时清零（遗物 / 能力可以保留） |
| 理智 | 上限 10 | 见 [01](01_核心机制.md) |
| 药水栏 | 3 | 战斗中随时使用，不耗能量 |

## 2. 回合流程

```
战斗开始
  ├─ 理智 = 上限；洗牌（「固有」牌放到抽牌堆顶）
  ├─ 触发 OnCombatStart（遗物、事件 buff）
  └─ 所有敌人决定首回合意图

┌▶ 玩家回合开始
│   ① 回合数 +1；若回合数 ≥ 4：侵蚀 −1 理智
│   ② 清空玩家格挡；能量 = 3
│   ③ 状态结算（回合开始类）；触发 OnTurnStart（遗物 / 能力）
│   ④ 抽 5 张牌（会被「束缚」减少）
│ 玩家行动阶段：打牌 / 用药水 / 结束回合
│ 玩家回合结束
│   ⑤ 手牌中的「回合结束」效果（疯语等）
│   ⑥ 触发 OnTurnEnd（「清明」类判定都放在这里）
│   ⑦ 弃掉手牌（「保留」除外，「虚无」的牌改为消耗）
│   ⑧ 状态结算（回合结束类，持续回合 −1）
│ 敌人回合（按从左到右的顺序）
│   ⑨ 清空该敌人的格挡
│   ⑩ 若被震慑：跳过行动，解除震慑；否则执行意图
│   ⑪ 该敌人的状态结算；决定下回合意图
└─ 所有敌人死亡 → 胜利；玩家生命 ≤ 0 → 失败
```

> 「清明」相关的持续效果统一在**回合结束**时判定，这样侵蚀（回合开始扣理智）不会让守夜流在判定前就失去清明。

## 3. 结算公式

### 3.1 伤害（逐段计算）

```
dmg = 基础值                       // 牌面数值（含升级）
dmg = dmg + 力量                    // 多段攻击每段都加
dmg = dmg × 0.75   若攻击者「虚弱」
dmg = dmg × 1.5    若目标「易伤」
dmg = max(0, floor(dmg))
先扣目标格挡，剩下的扣生命
```

- 遗物 / 能力的修正统一按**先加后乘**插入上面对应的步骤
- 卡面上的数字实时显示修正后的值：增益绿色，减益红色

### 3.2 格挡

```
blk = floor((基础值 + 敏捷) × (0.75 若「脆弱」))
```

### 3.3 理智

```
失去 N 理智：
  若来源 = 敌人 且 心防 > 0：心防 −1，本次损失作废
  理智 = max(0, 理智 − N)；若理智 = 0 → 崩溃结算
恢复 N 理智：
  实际增加 = min(N, 上限 − 理智)；溢出 = N − 实际增加
```

### 3.4 恐惧与震慑

```
对敌人施加 N 恐惧：
  若该敌人「无心智」或已被震慑：无效
  恐惧 += N
  若 恐惧 ≥ 意志：
      立即震慑 → 当前意图作废（下次行动跳过）
      恐惧 = 0
      意志 = ceil(意志 × 1.5)     // 收益递减，防止无限控制
```

- UI：敌人血条上方放一条「恐惧 / 意志」进度条，被震慑时意图图标打叉
- 恐惧不会自然衰减

### 3.5 打出一张牌的结算顺序

```
① 锁定卡面：按打出前的理智决定用清醒面还是癫狂面，本次结算中不再改变
② 支付能量
③ 支付代价；若理智因此归 0 → 先完整结算崩溃，再继续
④ 按卡面文字从上到下结算效果
     「清明：」在结算到该句时判定
     依赖理智数值的效果（明理之刃、崩坏边缘）取结算那一刻的值
⑤ 卡牌进入弃牌堆（「消耗」则移出本场）
```

- 设计意图：玩家拖牌时看到的那一面就是最终生效的那一面，代价不会在半路把卡翻面
- 例：理智 5 时打出撕裂 → 锁定清醒面（6 伤害）→ 付代价后理智 4，进入癫狂并触发调查笔记 → 结算 6 伤害

## 4. 关键词表

| 关键词 | 定义 |
|---|---|
| 消耗 | 打出后移出本场战斗 |
| 虚无 | 回合结束时若在手中，则消耗 |
| 固有 | 战斗开始时一定在起手 |
| 保留 | 回合结束时不弃掉 |
| **代价N** | 打出时失去 N 理智（理智不足也能打出，会导致崩溃） |
| **双面** | 癫狂时使用癫狂面（卡面显示当前生效的一面） |
| **清明：** | 理智 = 上限时附加的效果 |
| **心防** | 每层抵消一次来自敌人的理智损失 |
| **恐惧 / 意志 / 震慑** | 见 3.4 |
| **精神攻击N** | 敌人造成 N 点理智损失，无视格挡 |
| **无心智** | 免疫恐惧 |
| X 费 | 消耗当前全部能量，X = 消耗的能量数 |

## 5. 状态效果

| 状态 | 作用对象 | 效果 | 持续 |
|---|---|---|---|
| 力量 | 双方 | 每段攻击伤害 +N | 本场战斗 |
| 敏捷 | 玩家 | 卡牌获得的格挡 +N | 本场战斗 |
| 易伤 | 双方 | 受到的攻击伤害 ×1.5 | N 回合 |
| 虚弱 | 双方 | 造成的攻击伤害 ×0.75 | N 回合 |
| 脆弱 | 玩家 | 卡牌获得的格挡 ×0.75 | N 回合 |
| 束缚 | 玩家 | 下回合少抽 N 张牌 | 生效一次后清除 |
| 心防 | 玩家 | 见关键词 | 用掉为止 |
| 恐惧 | 敌人 | 见 3.4 | 不衰减，震慑时清零 |
| 震慑 | 敌人 | 跳过下一次行动 | 一次 |

> 回合制状态（易伤 / 虚弱 / 脆弱）在**持有者的回合结束时** −1，与尖塔一致。

## 6. 意图系统

### 6.1 意图类型

| 类型 | 图标显示（清醒） | 图标显示（癫狂） |
|---|---|---|
| 攻击 | 剑 + 数值（×段数） | 剑 |
| 防御 | 盾 | 盾 |
| 增益 / 减益 | 上箭头 / 下箭头 | 同左 |
| 精神攻击 | 眼睛 + 理智数值 | 眼睛 |
| 召唤 | 触须 | 触须 |
| 复合 | 多个图标组合 | 只显示类型组合 |
| 不可名状 | ? | ? |

### 6.2 敌人 AI 规则（招式表）

每个敌人都有一张招式表，每回合按以下顺序选招：

1. **强制招式**：首回合固定招式、阶段转换、计数器触发（如 Boss 潮位到 5）
2. **条件过滤**：去掉不满足条件的招式（如「生命 > 80% 时不治疗」「场上触须 ≥ 2 时不召唤」）
3. **重复限制**：同一招式不能连续用超过 N 次（默认 2）
4. **加权随机**：在剩下的招式里按权重抽取（用 `aiRng` 随机流，见 [08](08_技术方案.md)）

招式在**上回合结束时**就已经决定并显示，玩家永远是对着已知（或模糊）的意图做决策。
