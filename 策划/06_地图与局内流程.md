# 06 地图与局内流程

## 1. 单局结构

```
主菜单 → 开局（种子） → 地图（第 1 层）
   ↓ 选择节点
[战斗 / 精英 / 事件 / 商店 / 篝火 / 宝箱] → 奖励 → 回到地图 → … → 第 15 层（篝火）→ Boss → 结算
```

## 2. 地图生成

参考尖塔第一幕的生成规则：网格 **7 列 × 15 行**，第 16 层为 Boss。

### 2.1 路径

1. 第 1 行随机选一个起点，每一步只能连到上一行的左上、正上或右上节点，一直走到第 15 行
2. 重复生成 **6 条**路径；第 1、2 条的起点必须不同
3. 新路径的边不能和已有的边交叉（检测相邻两列之间的 X 形交叉）
4. 合并重叠的边，删掉没有连线的节点，第 15 行的所有节点都连到 Boss

### 2.2 房间分配

**固定层**

| 层 | 房间 |
|---|---|
| 1 | 普通战斗 |
| 9 | 宝箱 |
| 15 | 篝火 |
| 16 | Boss |

**其余层按权重随机**

| 房间 | 权重 |
|---|---|
| 普通战斗 | 53% |
| 事件 | 22% |
| 篝火 | 12% |
| 精英 | 8% |
| 商店 | 5% |

**约束**（不满足就重新抽，抽 N 次仍失败则退回普通战斗）

- 第 1–5 层不出精英和篝火
- 第 14 层不出篝火
- 精英、篝火、商店不能和父节点同类型（避免连续出现）
- 同一父节点的多个子节点，房间类型互不相同（保证分岔是真的选择）

### 2.3 地图表现

- 羊皮纸海图风格，节点用手绘图标；已走的路径用墨迹连线
- 显示每个节点的类型；事件节点显示「?」
- 支持预先规划路线：悬停某个节点时高亮所有通往它的路径

## 3. 节点详解

| 节点 | 内容 |
|---|---|
| 普通战斗 | 从遭遇池抽一组敌人（见 [04 §3](04_敌人设计.md)） |
| 精英 | 3 个精英中抽一个，同一局内不重复 |
| 事件 | 从事件池抽一个，同一局内不重复 |
| 商店 | 见 §5 |
| 篝火 | 三选一，见 §6 |
| 宝箱 | 1 件遗物（普通 50% / 罕见 33% / 稀有 17%）+ 25–50 金币 |
| Boss | 溺亡司祭；胜利后进入 Demo 结算画面 |

## 4. 战斗奖励

| 来源 | 金币 | 卡牌 | 遗物 | 药水 |
|---|---|---|---|---|
| 普通战斗 | 10–20 | 3 选 1（可跳过） | — | 按药水概率 |
| 精英 | 25–35 | 3 选 1 | 1 件（普通 50% / 罕见 33% / 稀有 17%） | 按药水概率 |
| Boss | — | — | — | — |

### 4.1 卡牌稀有度

| 来源 | 普通 | 罕见 | 稀有 |
|---|---|---|---|
| 普通战斗 | 60% | 37% | 3% |
| 精英 | 50% | 40% | 10% |
| 商店 | 按商店规则 | | |

**稀有保底偏移**（尖塔机制）：维护一个偏移值，初始 −5%；每出现一张普通卡 +1%，出现稀有卡时重置为 −5%。实际稀有率 = 基础稀有率 + 偏移（下限 0）。

### 4.2 药水掉落

基础概率 40%；本场掉落后 −10%，没掉落 +10%（限制在 0–100%）。药水栏满时仍会显示奖励，玩家可以丢弃一瓶来替换。

## 5. 商店

| 商品 | 数量 | 价格（金币） |
|---|---|---|
| 角色卡 | 5 张（攻击 2 / 技能 2 / 能力 1） | 普通 45–55，罕见 68–82，稀有 135–165；随机一张打 5 折 |
| 遗物 | 3 件（其中 1 件为商店专属） | 普通 143–157，罕见 238–262，稀有 285–315 |
| 药水 | 3 瓶 | 普通 48–52，罕见 72–78 |
| 删卡服务 | 每次进店 1 次 | 75 起，每使用一次 +25（整局累计） |

## 6. 篝火（三选一）

| 选项 | 效果 |
|---|---|
| 休息 | 恢复 30% 最大生命 |
| 锻造 | 升级 1 张牌 |
| 静思 | 理智上限 +1；**或者**移除 1 张疯语（有疯语时二选一） |

> 静思给崩溃过的堕落流留了一条清理诅咒的通道，也给事件里扣过理智上限的守夜流一条回补通道。

## 7. 经济目标

| 指标 | 目标值（一局） |
|---|---|
| 普通战斗场次 | 7–9 |
| 精英场次 | 1–3 |
| 总收入金币 | 300–400（不含事件） |
| 商店访问 | 1–2 次 |
| 删卡次数 | 1–2 |
| 最终牌组规模 | 18–24 张 |

> **金币目标和 §4 的奖励表对不上**（2026-10-18 模拟，[07 §8.2](07_数值框架.md)）：按奖励表，7 场普通战斗 × 15 + 1 场精英 × 30 + 宝箱约 37，一局金币收入的期望只有 170–180，模拟结果 174–184。要达到 300–400，普通战斗需要给 25–35 金币。两者改哪一个待定（[09 §5.4](09_开发计划.md)），商店价格也要跟着这个数定

## 8. 存档

- 自动存档点：**进入节点**、**战斗结束进入奖励界面**、**回到地图**（局状态 + 随机数流状态，见 [08](08_技术方案.md)）。存档带 `version` 字段，先写临时文件再改名，写到一半中断不会损坏旧档
- 战斗中退出后重新进入，会回到这场战斗的开始；随机数是确定性的，重开后起手牌和首回合意图都完全相同，靠反复读档刷好运气没有意义
- 局外只保存设置和统计数据（Demo 不做解锁系统）
