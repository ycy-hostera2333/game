# 10 美术策划

> 本文定美术方向、规格、资产清单和生产路线。表现层的实现方式见 [08 §9](08_技术方案.md)，阶段安排见 [09](09_开发计划.md)。
>
> **先看结论**：按 §12.1 估算，Demo 全部正式美术约 **330 小时**，只做必需的 P0 也要约 **155 小时**，已经超过 [09](09_开发计划.md) 给整个 Demo 排的总工时（每周 8–10 小时 × 12–14 周 ≈ 100–140 小时）。所以美术的默认策略是：**版式和着色器先做到正式质量，插图用风格化灰盒一路用到阶段 5，正式插图先只做 P0**。方向、生产路线和范围已于 2026-10-17 确认，见 §13。

## 1. 美术方向

### 1.1 风格定义

**19 世纪铜版蚀刻 / 木口木刻插图 + 单一强调色（深渊青）。**

- 明暗只靠排线密度表达，不用渐变、不用喷枪
- 底色是旧纸，线条是暖黑墨；插图本身没有颜色，颜色只出现在承载信息的地方（§2）
- 时代感：煤气灯、渔港、维多利亚式教堂，和世界观「灰潮镇」一致

| 参考 | 借什么 | 不借什么 |
|---|---|---|
| 古斯塔夫·多雷《古舟子咏》（1876）插图 | 海、雾、亡灵船的排线手法；大面积留白和密排线的对比 | 过于繁密的全幅构图（缩到手牌尺寸会糊成一片灰） |
| 海克尔《自然界的艺术形态》（1904） | 水母、管水母、放射虫的形态，用作触须和「深海之物」的造型来源 | 彩色石印的配色 |
| 《挑战者号科考报告》（1880–1895）深海生物图版 | 鳞民、深海生物的解剖式描绘 | — |
| 《Pentiment》 | 纸面 UI、文字即画面的一部分 | 手抄本的彩色装饰 |
| 《暗黑地牢》 | 大块实墨剪影带来的可读性 | 浓重的整屏暗色（我们的清醒态是亮纸面） |
| 《杀戮尖塔》 | 卡面结构、意图和手牌的交互惯例 | 卡面配色体系 |

### 1.2 美术支柱

1. **只有墨与纸**：插图源文件只有灰度（墨的覆盖率），颜色全部由着色器施加。换一套色板只需改一个 `PaletteSO`（§11.4）
2. **青绿只属于深渊**：深渊青只用于理智、癫狂和「来自深海的东西」（深潜者的眼、触须的荧光、潮水）。其他任何元素都不许用青色
3. **清醒看见数字，癫狂看见真相**：理智越低，UI 遮住的数字越多，画面里显露的东西越多。主要的表现手段是「癫狂层」：卡图、敌人、背景、主角都可以带一层只在癫狂时显现的墨线（多出来的眼、影子里的触须）
4. **信息先于氛围**：后处理只作用于战斗舞台，不碰卡牌和数字；颜色永远不是唯一的信息载体，必须同时有图标形状或文字

### 1.3 机制到画面的映射

| 机制 | 画面表现 |
|---|---|
| 理智（[01 §2](01_核心机制.md)） | **纸有多白**：理智越低，墨从画面四角渗进来越多 |
| 清明（理智 ≥ 上限 − 1） | 理智条顶端描金；卡面上「清明：」那一句点亮为金色 |
| 癫狂（理智 ≤ 4） | 双面牌翻到**反相面**（深底青线）；场景出现癫狂层；意图数字被墨渍盖住 |
| 崩溃（理智 = 0） | 一帧全屏反相 + 裂纹贴图 |
| 恐惧 / 震慑 | 紫灰色同心波纹；震慑时意图被墨线划叉 |
| 侵蚀 | 理智条上预告下回合要熄灭的那一格（回应 [试玩记录](../原型/试玩记录_2026-10-17.md) 问题 4） |
| Boss 潮位 | 水位计；满 5 格时潮水从屏幕底部漫上来 |

## 2. 色彩规范

### 2.1 色板

亮底 = 纸面（清醒态的卡、UI 面板）；暗底 = 深渊（癫狂面的卡、深色弹窗）。对比度按 WCAG 公式计算，正文要求 ≥ 4.5。

| Token | 亮底色值 | 暗底色值 | 用途 | 对比度（对本底） |
|---|---|---|---|---|
| `paper` 纸 | `#E8E0CC` | — | 清醒态底色 | — |
| `paper-shade` 纸影 | `#CFC6B0` | — | 面板第二层、未点亮的格子 | 墨 10.2 |
| `ink` 墨 | `#1C1A17` | — | 线条、正文 | 13.2 |
| `ink-mid` 淡墨 | `#4A453C` | — | 次要文字、背景排线 | 7.2 |
| `abyss` 深渊底 | — | `#0F1B1B`（屏幕）/ `#132423`（卡面） | 癫狂面底色、深色弹窗 | — |
| `pale` 月白 | — | `#D8E4DF` | 暗底上的正文 | 12.3 |
| `teal` 深渊青 | `#1A615E` | `#4FC2B0` | 理智、代价、癫狂、深海之物 | 5.5 / 7.4 |
| `gold` 清明金 | `#7D5914` | `#D9A84A` | 清明、理智恢复、守夜徽记、金币 | 4.8 / 7.4 |
| `blood` 血 | `#8E2A2A` | `#E0736A` | 生命、伤害、堕落徽记 | 6.4 / 5.2 |
| `dread` 恐惧紫 | `#5B4A6E` | `#A898C0` | 恐惧、意志、传染徽记 | 6.0 / 6.1 |
| `moss` 苔绿 | `#3D6B2E` | `#8FC27A` | **只用于**被增益修正过的卡面数字 | 4.8 / 7.8 |

- 纸面原型里的青 `#1F6F6B` 在纸底上对比度只有 4.5，金 `#A8791F` 只有 3.0，正式版分别加深为上表的值。原型打印件不用改
- 02 §3.1 规定卡面数字「增益绿色、减益红色」，这里用苔绿和血色实现

### 2.2 用色规则

1. **面积**：深渊青是唯一允许大面积出现的颜色（癫狂面卡底、后处理、潮水）；金、血、紫、绿只用于数字、小图标、徽记和不超过 10px 宽的色条
2. **插图里只允许出现深渊青**，而且只能通过「深渊遮罩」通道施加（§11.2），不能直接画进源文件
3. **颜色不是唯一载体**。实测：用 Machado 模型模拟绿色盲（deuteranopia），金 `#7D5914` 变成 `#6F6317`，血 `#8E2A2A` 变成 `#5F5627`，两者几乎无法区分。因此：
   - 生命永远配心形，清明永远配提灯，恐惧永远配波纹，理智永远配理智格
   - 卡面数字的增减益，悬停时弹出算式（如「6 + 2 力量 × 0.75 虚弱 = 6」），不只靠颜色
4. 不做单独的色盲模式；`PaletteSO` 支持整套替换，以后需要高对比色板时直接加一套

| 事件 | 颜色 | 字号（1080p） | 前缀图标 |
|---|---|---|---|
| 造成 / 受到伤害 | `blood`，2px 墨描边 | 48（单次 ≥ 20 时 64） | — |

## 3. 线条与明度规范

工作画布 = 导出尺寸的 2 倍（§11.1），以下线宽都按**工作画布**计。

| 项 | 卡图 / 事件 | 敌人 / 主角 | 背景 | 图标 |
|---|---|---|---|---|
| 外轮廓 | 8–10px | 10–12px | 4px，或不勾外轮廓 | 6px |
| 结构线 | 4–6px | 5–6px | 2–3px | 3px |
| 排线 | 2–3px，间距 ≥ 8px | 同左 | 2px，间距 ≥ 10px | **不用排线**，用实墨块 + 留白 |
| 最大墨密度 | 100% | 100% | **≤ 40%**（只用 `ink-mid` 色阶） | 100% |

- **三层明度**：背景浅且低对比 → 角色高对比、粗轮廓 → UI 纸面卡片加墨框。角色永远比背景更黑，这是可读性的底线
- **剪影测试**：敌人、主角、图标填成纯黑后仍然能认出是什么
- **缩略图测试**：卡图缩到手牌里的插图窗大小（208 × 144px）后，主体和大块明暗关系仍然成立。细排线在这个尺寸会被 mipmap 平均成灰色，这是预期效果，不是问题
- **安全区**：卡图主体放在插图窗中心 70% 以内，因为攻击牌的尖拱窗和能力牌的圆窗会裁掉四角
- 光源统一在**左上**；角色朝向统一：主角面朝右，敌人面朝左

### 4.2 类型、稀有度、流派的区分

三个维度分别用**形状、装饰、颜色**表达，互不重叠：

| 维度 | 表达方式 | 取值 |
|---|---|---|
| 类型 | 插图窗形状（哥特建筑母题） | 攻击 = 尖拱窗 ／ 技能 = 倒角方窗 ／ 能力 = 圆窗 ／ 诅咒 = 墨渍破窗 ／ 状态 = 虚线方窗 |
| 稀有度 | 框饰复杂度（不用颜色） | 基础 = 单线框 ／ 普通 = 单线框 + 四角铆饰 ／ 罕见 = 双线框 + 卡名单层旗带 ／ 稀有 = 双线框 + 蚀刻花边 + 卡名双层旗带 |
| 流派 | 顶部色条 + 卡名左侧徽记（24px） | 守夜 = 金 + 提灯 ／ 堕落 = 血 + 裂眼 ／ 传染 = 紫 + 波纹 ／ 通用、基础 = 淡墨 + 无徽记 |

### 4.3 双面牌

- **清醒面**：纸底墨线，和普通卡一样
- **癫狂面**：同一张插图做**反相**处理，纸 → `abyss`，墨 → `teal` 发光色，正文改用 `pale`；同时显现这张卡的**癫狂层**（§4.6 表格「癫狂层」一列）。框饰换成「侵蚀」变体：边框上长出藤壶和触须
- 一张双面牌只画一张底图 + 一层癫狂层，**不画两张插图**，11 张双面牌省下约 11 张卡图的工时
- **翻面**：墨从卡牌底部向上渗透溶解，0.3 秒（[08 §9](08_技术方案.md)）；所有在手的双面牌同时翻
- **角标 ◐**：右上角，表示这是双面牌。清醒面显示右半青色（「坠落后更强」），癫狂面显示反相。[09 §4](09_开发计划.md) 提出用角标标出「另一面更强 / 更弱」；按 [01 §2.6](01_核心机制.md)，癫狂面收益固定是清醒面的 1.6–1.8 倍，所以角标只需要表达「有另一面」
- **悬停预览**：悬停时在卡牌右侧以 70% 大小并排显示另一面，标注「清醒面 / 癫狂面」

### 4.4 动态信息

| 情况 | 卡面表现 |
|---|---|
| 「清明：」条件满足 | 这一句变为 `gold`，卡牌外缘加一圈金色微光 |
| 「清明：」条件不满足 | 这一句变为 `ink-mid` 50% 透明度 |
| 「代价N」 | 关键词恒为 `teal` 加粗（沿用纸面原型） |
| 数值被修正 | 增益 `moss`，减益 `blood`；悬停弹出算式（§2.2） |
| 已升级 | 卡名后加「+」，被升级改动的数值下加一条细线 |
| 无法打出（能量不足） | 费用圈变 `blood` 描边，整卡降到 60% 亮度 |

### 4.5 状态牌与诅咒

- **疯语**（诅咒）：墨渍破窗，整张卡底是满纸潦草重复的字迹；卡名用手写体
- **缠网**（状态）：虚线方窗，卡面颜色降到 `paper-shade`，让它在手牌里一眼看出是垃圾牌

## 7. 癫狂表现

### 7.1 全局参数

BattleDirector 收到 `SanityChanged` 时，把理智换算成 `_Lunacy`（0–1），用 0.5 秒补间写入全局着色器参数。后处理、背景和敌人的癫狂层、主角影子都读这一个值，保证所有表现同步。

### 7.2 按理智分级

| 理智 | `_Lunacy` | 暗角 | 色差 | 波纹 | 癫狂层 |
|---|---|---|---|---|---|
| ≥ 上限 − 1（清明） | 0 | 0 | 0 | 0 | 无；纸色略微提亮 |
| 5 至 上限 − 2 | 0 | 0 | 0 | 0 | 无 |
| 4（进入癫狂） | 0.4 | 0.25 | 0.10 | 0 | 显现 40%；进入瞬间墨从四角渗入 0.5 秒 |
| 3 | 0.55 | 0.32 | 0.15 | 0 | 55% |
| 2 | 0.7 | 0.40 | 0.20 | 0.10 | 70% |
| 1 | 0.85 | 0.48 | 0.30 | 0.20 | 85%，背景里的触须影子开始缓慢移动 |
| 0（崩溃） | — | — | — | — | 0.08 秒全屏反相 + 裂纹贴图 0.6 秒淡出 + 屏幕震动 12px，之后回到理智 3 的强度 |

实现（阶段 2 灰盒）：没有用 URP Volume。灰盒的舞台和 UI 在同一张画布上，全屏后处理会连卡牌和数字一起扭曲，违反 §1.2 支柱 4。改成舞台层自己实现：暗角是一张盖在战场上、UI 之下的全屏图（`Deeptide/UI/InkVignette`，墨从四角带噪声渗入，底下铺一层很淡的深渊青）；色差和波纹在角色剪影的着色器里做（`Deeptide/UI/Stage`，读全局 `_Lunacy`）。分级和数值同上表。以后舞台换成独立相机渲染时，可以再换回 Volume。

### 7.3 其他全屏效果

| 效果 | 触发 | 表现 |
|---|---|---|
| 刺目强光 | 灯塔守望者被动，每回合开始 | 0.3 秒过曝，纸色泛白，和癫狂的「变暗」方向相反 |
| 潮水 | Boss 潮位满格，直到大潮结算 | 屏幕底部约 22% 高度漫上 `teal` 半透明水面，上沿是向左流动的波纹（初稿写 15%，但底部 15% 几乎全被手牌挡住，实测改成刚好露出手牌边缘、停在血条下面） |
| 深海之歌 | Boss 二阶段常驻 | 背景癫狂层至少显现 50%，不受理智影响 |

### 7.4 可访问性

设置里提供：

- **降低癫狂特效**：后处理强度 × 0.3，关闭波纹和崩溃的反相闪烁（反相只闪一次、不超过每秒 3 次，本身已低于光敏风险线，但仍给出关闭选项）
- **屏幕震动**开关
- 意图抖动和墨渍**不受**这个选项影响，因为它们承载的是「信息被遮住」这一机制信息

## 10. 灰盒规格（阶段 2–4）

灰盒的目标是**版式、尺寸、交互一次到位**，以后换美术不动代码、不动预制体。

| 项 | 灰盒做法 |
|---|---|
| 卡面 | 沿用纸面原型的版式：费用圈、流派色条、印章框里放卡名首字（如「刃」）、正文。尺寸直接用 §4.1 的正式尺寸，由 CSV 自动生成 |
| 卡框 | 三种窗形先用简单几何形（尖角 / 方 / 圆），稀有度用线框粗细区分 |
| 敌人 | 纯墨剪影 + 名称，尺寸按 §5.1 档位，这样意图、血条的位置一次定好 |
| 图标 | 几何图形 + 一个汉字（攻 / 防 / 增 / 减 / 神 / 召 / ?） |
| 背景 | 纯 `paper` 色 + 纸纹噪点 |
| 着色器与后处理 | **做到正式质量**：翻面、癫狂后处理、意图模糊是机制的一部分（阶段 2 验收要求「新手能看懂意图模糊」），不依赖插图 |

## 11. 技术规格

### 11.1 尺寸

统一规则：**源图 = 1080p 显示尺寸的 2 倍**（即 4K 原生）；工作画布再放大 2 倍画线稿，导出时缩小。

| 类别 | 1080p 显示 | 导出尺寸 | 工作画布 |
|---|---|---|---|
| 卡面（整卡） | 240 × 336 ～ 440 × 616 | 720 × 1008 | — |
| 卡图（插图窗） | 208 × 144 ～ 312 × 216 | 624 × 432 | 1248 × 864 |
| 敌人 / 主角 | 见 §5.1 | 见 §5.1 | 导出 × 2 |
| 战斗背景 | 1920 × 1080 | 2560 × 1440（低对比的淡排线放大到 4K 损失可接受） | 同导出 |
| 事件插图 | 960 × 640 | 1920 × 1280 | 同导出 |
| 地图底图 | 1920 × 3400（卷动） | 1920 × 3400 | 同导出 |
| 遗物 / 药水 / 意图 / 地图节点图标 | 56–64 | 128 | 256 |
| 状态图标 | 32 | 64 | 128 |
| 主视觉 | 1920 × 1080 | 3840 × 2160 | 同导出 |

### 11.2 打包贴图

插图、敌人、背景、事件统一打包成一张 RGBA 贴图，颜色全部由着色器从 `PaletteSO` 读取：

| 通道 | 内容 | 来自源文件的图层 |
|---|---|---|
| R | 墨的覆盖率（0 = 纸，1 = 墨） | `ink` |
| G | 深渊遮罩（1 = 着深渊青） | `abyss`（可选） |
| B | 癫狂层的墨（显现程度 = `_Reveal`） | `mad`（可选） |
| A | 本体轮廓（不透明素材恒为 1） | `fill` ∪ `ink` 的 alpha |

- 着色器里：`color = lerp(paper, ink, R)` → 叠深渊青 `G` → 叠癫狂层 `B × _Reveal`；最终 alpha = `max(A, B × _Reveal)`，所以癫狂层可以长出本体轮廓之外（触须伸出身体）
- 卡牌的 `_Reveal` 由翻面状态驱动，战斗舞台上的素材由全局 `_Lunacy` 驱动
- 画师只导出分层 PNG，编辑器工具 `ArtPacker` 按文件名后缀自动打包
- **打包贴图是数据不是颜色，导入时关掉 sRGB**

### 11.3 导入设置

| 类别 | sRGB | Mipmap | 压缩 | 图集 |
|---|---|---|---|---|
| 打包贴图（卡图、敌人、背景、事件） | 关 | 开（显示时会缩放，mipmap 能避免细排线闪烁和摩尔纹） | BC7 | 否 |
| 卡框、UI 套件 | 开 | 开 | BC7 | `UI` |
| 图标（单通道墨 + alpha，由 Image 着色） | 开 | 开 | BC7 | `Icons` |
| 特效序列帧 | 开 | 开 | BC7 | `VFX` |

- **全部开 mipmap，三线性过滤，mip 用 Kaiser 滤波**（2026-10-25 改）。原表里卡框、图标、特效不开 mip，是按 1:1 显示设想的；实际卡框在手牌里缩到 1/3、意图图标缩到 0.4，不开 mip 的双线性缩小把细线采成断续的锯齿，试玩反馈「锯齿感比较强」。Kaiser 比默认的 Box 更接近低通，细排线缩小后成灰而不是出摩尔纹。程序生成的灰盒贴图（`Shapes`）同样带 mip

Demo 规模下，所有资源都由 `ArtDatabase`（[08 §4](08_技术方案.md)）直接引用，不上 Addressables。
