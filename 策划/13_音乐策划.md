# 13 音乐策划

> 2026-10-26 初稿。本文定音乐和音效的方向、动态音乐规则、曲目与音效清单、技术规格和生产路线。故事背景见 [12](12_叙事与世界观.md)，画面规则见 [10](10_美术策划.md)，阶段安排见 [09](09_开发计划.md)。工程里目前还没有任何音频。
>
> **先看结论**
>
> - 恐怖走**慢性的不安**：低频、微失谐、时间错位、留白。不做 jump scare
> - 核心手法叫**叠夜**：理智越低，同一段音乐上叠的拷贝越多，每份都错开一点、走音一点（[12 §5](12_叙事与世界观.md)「癫狂 = 所有夜晚叠在一起」）。音乐直接读 `LunacyFx.Current`，和画面的 `_Lunacy` 是同一个值
> - **声音不撒谎**：理智、癫狂、潮位这几种信号的音色是保留的，吓人的环境声不许冒用；音效也不能泄露被模糊的意图
> - Demo 的 P0 是地图、战斗、Boss 三首可分层的曲子，加 6 个短乐句、32 个音效。自己做约 70 小时；默认由 Claude 程序化合成 + CC0 采样来做，你的时间主要花在听和录一段人声上，约 10 小时
> - 用 Unity 自带的 AudioMixer，不上 FMOD / Wwise
> - §8 的 5 项已按建议确认（2026-10-26）；样张三件套已合成，等你听审（§7.4）

## 1. 方向

### 1.1 什么样的恐怖

一局 35–50 分钟，大半时间在战斗里，战斗曲一局要听 20 分钟以上。恐怖必须是能长时间听下去的那种。

| 要 | 不要 |
|---|---|
| 慢性的不安：低频、微失谐、时间错位 | Jump scare。回合制、一局 40 分钟，吓第一次是惊喜，吓到第十次就烦了；突然的巨响还会盖住要读的信息 |
| 熟悉的东西慢慢变形：几个主题反复出现，一次比一次走样（§2.3） | 一直尖叫、刺耳的高频、整首都是噪声 |
| 留白和突然的安静：最响的两个时刻（大潮、崩溃）前面都先空一拍 | 用吓人的声音冒充游戏信号（§3.6） |
| 声音来自画面外：雾里、身后、水下 | 恐怖片音效库里的通用货：心跳、女鬼笑、尖啸 |

| 参考 | 借什么 | 不借什么 |
|---|---|---|
| 《暗黑地牢》 | 战斗曲按压力分层叠加；旧乐器的时代感 | 旁白、密集的战鼓 |
| 《邪恶冥刻》（Inscryption） | 小编制、低保真，卡牌桌上的不安 | 风格中途大换 |
| 《寂静岭 2》 | 旋律和噪声并存；环境声「哪里不对」 | 工业摇滚段落 |
| 《失忆症：黑暗后裔》 | 理智低时声音跟着变形 | 幻听冒充真实威胁（我们的规则是声音不撒谎） |
| 《奥伯拉丁的回归》 | 海事题材；短促的叙事乐句 | — |
| 《渔帆暗涌》（Dredge） | 渔港 + 深海不可名状，平静和恐惧的切换 | 偏暖的民谣主调 |
| 利盖蒂《大气》《永恒之光》 | 微复调：很多声部各自错开一点，叠成一片雾。叠夜就是这个思路 | — |
| 史蒂夫·赖希《钢琴相位》 | 同一段音乐的两份拷贝慢慢错开 | 机械的重复感 |
| 潘德列茨基《广岛受难者的挽歌》 | 弦乐音簇，用在崩溃 | 整首的强度 |

### 1.2 音乐支柱

和 [10 §1.2](10_美术策划.md) 的美术支柱一一对应。

1. **清醒只有一夜，癫狂是所有夜晚**：理智越低，叠夜的拷贝越多（§3）。混响也是别的夜晚的回声：清明时最干、最近，癫狂时最湿、最远
2. **深渊的声音只属于深渊**：水下低通、低频呼吸、弓擦金属、无词低合唱、倒放，只用于理智、癫狂和深海之物，和深渊青的用色规则一样。别的地方不许用
3. **声音不撒谎**：对应 [01 §2.7](01_核心机制.md) 和 10 支柱 4。游戏信号的音色是保留的（§3.6）；幻听只说真话（§3.5）；敌人出招前的声音不按数值分档，否则癫狂时等于把意图念出来
4. **安静比响更吓人**：默认整体音量偏低，留出动态；进入癫狂、大潮、崩溃之前都先空一拍。叠夜加层时总响度不变，癫狂是**更浑**，不是**更响**

### 1.3 机制到声音的映射

| 机制 | 声音 |
|---|---|
| 理智 | 叠夜层数、失谐、低通、混响（§3.3）；失去 / 恢复理智的音效用音高报出剩下多少（§5.2 R01） |
| 清明（理智 ≥ 上限 − 1） | 混响降到最低，加一条清亮的高音线（清明层） |
| 进入癫狂 | 音乐空一拍 →「深潮的呼吸」→ 带着叠夜层回来（§3.4） |
| 离开癫狂 | 叠夜层像倒放一样收回去 |
| 崩溃 | 所有层挤成一个音簇猛涨，和画面反相同一帧切成全静，0.6 秒后回来 |
| 侵蚀 | 第 4 回合起每回合开始，一滴水落进很深的井。叠夜的拷贝会随时间越错越开（§3.2），仗拖得越久，声音越乱 |
| 疯语 | 手里每有一张疯语，多一层耳语（§3.5） |
| 心防 | 盐粒撒落、玻璃罩扣下 |
| 恐惧 / 震慑 | 弦乐颤音扫向目标 / 鹅毛笔划叉 + 一声被掐断的惊喘 |
| 点亮提灯、鲸油灯 | 划火柴。灯只让意图看得清，不改理智，所以叠夜层不变 |
| Boss 潮位 0–7 | 7/4 拍，每小节 7 拍对应祭坛上的 7 道凹槽；潮位 N 时，前 N 拍各有一声水下钟和一声低声数数（§4.3） |
| 大潮 | 潮位 5 起加一层永远在上升的谢泼德音；大潮时数到「七」，空一拍，砸下来 |
| 深海之歌 | Boss 二阶段，前面所有主题放慢 8 倍叠在最底下，每一句都是一个别的夜晚 |
| 回潮（死亡） | 所有声音倒放 1.5 秒（夜被折回去）→ 安静 → 潮钟七下 → 栈桥的浪 |

## 2. 声音调色板

### 2.1 乐器与声源

全部是煤气灯时代渔港里听得到的东西，不用电子合成器的明显音色（合成可以用，但听起来要像真东西）。

| 声源 | 用在 | 规则 |
|---|---|---|
| 簧风琴（小教堂用的脚踏风琴） | 地图的底、潮信会赞美诗、Boss 一阶段 | 潮信会和教堂的声音 |
| 旧立式钢琴（略走音） | 地图旋律、R01 失去理智 | 走音量固定，不随理智变（随理智变的只有叠夜） |
| 八音盒 | 导师主题、开局的信、梦中的导师 | 只属于导师 |
| 大提琴、低音提琴 | 战斗的主声部、篝火 | 拨弦、琴马附近拉（sul ponticello）、弓杆击弦（col legno）；少用长旋律 |
| 六角手风琴 | 网缚渔夫、商店华尔兹 | 水手的声音 |
| 潮钟（低沉的大钟） | 回潮、Boss 潮位、Demo 结局、标题 | **保留音色**，只表示回潮和潮位 |
| 手铃（小铃） | 雾中商贩 | 事件原文「雾里传来铃声」 |
| 雾笛 | 地图、灯塔守望者 | — |
| 人声 | 低声数数（Boss）、无词低合唱（深海之歌）、耳语（疯语） | 都不唱歌词。数数和耳语可以自己录（§8 第 3 条） |
| **深渊层** | 弓擦金属（锯琴、弓擦镲）、水琴、水下低通、30–60 Hz 的呼吸、倒放 | **保留**给理智、癫狂和深海之物（支柱 2） |
| 环境 | 浪、木桩和绳子的吱呀、煤气灯的嘶声、乌鸦、雨 | — |

### 2.2 调式、速度、拍子

- 主调 **D 弗里几亚**（D E♭ F G A B♭ C）。小二度 D–E♭ 是「深潮的呼吸」，所有主题都从它长出来
- 潮钟定在低音 D。钟本身的谐波里有一个偏小三度的音，天然发阴
- **三全音 D–A♭ 只在癫狂层和 Boss 里出现**。清醒态尽量用空五度、八度，像纸面一样空；癫狂态加小二度音簇
- 速度：地图约 56（自由节奏）；战斗 76，4/4；Boss 76，**7/4**

### 2.3 主题动机

五个动机贯穿全部曲目。玩家第一次听见是原样，后面每次都走样一点，到 Boss 二阶段全部沉到水底（§4.3）。

| 动机 | 形态 | 首次出现 | 变形 |
|---|---|---|---|
| 深潮的呼吸 | 低音 D – E♭ – D，一吸一呼，很慢 | 第一次进入癫狂 | 深海之歌里放慢 8 倍，变成整首的底 |
| 潮钟七下 | 低钟 D 敲七下 | 第一次死亡（回潮） | Boss 潮位层里按潮位只敲前 N 下 |
| 栈桥 | 大提琴 + 旧钢琴，一句 8 小节的旋律 | 标题、地图 | 商店：3/4 华尔兹 + 走音八音盒；篝火：大提琴只拉前半句，不拉完 |
| 潮信会赞美诗 | 簧风琴四部和声，7 拍一句 | 教团集会事件、地图第 11 层起的远处 | Boss 一阶段的主体；第 3 夜起的事件变体里，唱的变成数数（[12 §7.2](12_叙事与世界观.md)） |
| 导师（信） | 八音盒，7 个音的摇篮曲短句 | 开局的信、梦中的导师 | Boss 褪去人形：降两个八度、低通、拖慢一倍，只放前 4 个音，像从水下传上来 |

导师动机藏进 Boss 二阶段，对应 12 的反转「导师 = 溺亡司祭」（2026-10-26 已确认保留）。

## 3. 动态音乐：叠夜

### 3.1 分轨结构

每首可循环的曲子由几条**等长**的分轨组成，同时起播，按参数调各自的音量：

| 分轨 | 内容 | 驱动 |
|---|---|---|
| 底 | 持续音、脉冲 | 常开 |
| 主 | 和声 + 旋律 | 常开；叠夜拷贝的来源 |
| 清明 | 一条清亮的高音线（小提琴泛音或玻璃音） | 清明时开 |
| 叠夜 1–4 | 「主」的拷贝（§3.2） | 理智 |
| 深渊 | 低频呼吸 + 弓擦金属 | 理智；Boss 二阶段强制 ≥ 50% |
| 曲目专属 | 地图的层段、Boss 的潮位、精英层 | 各自的参数 |

### 3.2 叠夜怎么做

叠夜的拷贝**不另外录**，就是同一条「主」分轨，运行时多开几个 AudioSource 播放，每个晚一点起播、音高偏一点：

| 拷贝 | 起播延迟 | 音高偏移 | 相对「主」的音量 |
|---|---|---|---|
| 叠夜 1 | 1/3 拍 | −15 音分 | −6 dB |
| 叠夜 2 | 1/2 拍 | +20 音分 | −8 dB |
| 叠夜 3 | 3/4 拍 | −30 音分 | −10 dB |
| 叠夜 4 | 1 拍 | +40 音分 | −12 dB |

- Unity 的 `pitch` 是变速变调，所以偏了音分的拷贝也会越播越错开：叠夜 1 每分钟落后约 0.5 秒，叠夜 4 每分钟领先约 1.4 秒，大约是 1.8 拍。每场战斗从头起播，**战斗拖得越久，拷贝错得越开**，这正好就是侵蚀在故事里的意思（12 §5「仗拖得越久，别的夜晚漫上来得越多」）
- 拷贝从战斗开始就一直在播（音量 0），理智变化时只调音量，不重新起播，所以不会有接缝
- 不占额外的存储和内存；变速重采样很便宜
- 每加一层，「主」自己降 1 dB，保持总响度不变（支柱 4）
- 作曲时要照顾这件事：「主」分轨叠上自己的错位拷贝以后还得能听。旋律稀疏、长音多、音符之间留空的写法效果最好，密集的快速音型叠起来会糊成噪声

### 3.3 按理智分级

和 [10 §7.2](10_美术策划.md) 同一张分级表，读同一个 `_Lunacy`。

| 理智 | `_Lunacy` | 叠夜层 | 叠夜低通 | 混响送量 | 深渊层 | 清明层 | 音乐总线补偿 |
|---|---|---|---|---|---|---|---|
| ≥ 上限 − 1（清明） | 0 | 0 | — | −24 dB（几乎干） | 0 | 开 | 0 |
| 5 至 上限 − 2 | 0 | 0 | — | −14 dB | 0 | 关 | 0 |
| 4（进入癫狂） | 0.4 | 1 | 8 kHz | −10 dB | 40% | 关 | −1 dB |
| 3 | 0.55 | 2 | 5 kHz | −8 dB | 55% | 关 | −1.5 dB |
| 2 | 0.7 | 3 | 3.5 kHz | −6 dB | 70% | 关 | −2.5 dB |
| 1 | 0.85 | 4 | 2.5 kHz | −4 dB | 85%，「主」本身也低通到 6 kHz | 关 | −3.5 dB |
| 0（崩溃） | — | 见 §3.4 | | | | | |

- 每层在对应的阈值处 0.5 秒淡入淡出，和画面的补间时长一致
- **混响送量**指湿声比干声低多少。混响本身要校准到响度增益 0 dB：长尾巴叠起来的能量会让湿声比送量高出约 6.5 dB，不校准的话理智 1 的湿声会盖过干声（样张实测，§7.4）
- **音乐总线补偿**也是样张实测出来的：只靠「每加一层叠夜，『主』降 1 dB」不够，混响送量和深渊层一起涨，理智 1 会比理智 7 响 3.4 LU。加上补偿后，6 档的整体响度都在 −24.0 到 −24.2 LUFS。分轨、叠夜音量或送量一改，就重跑 `build.py --calibrate` 重新量（`AudioSource/README.md`）
- **叠夜只听理智**。Boss 可以把深渊层拉高（深海之歌），但不能动叠夜层；叠夜层数永远等于理智给出的层数，玩家闭眼也能靠它判断自己有多深
- 清明不在 `_Lunacy` 里（清明和中段都是 0），由 AudioDirector 按 `SanityChanged` 和上限自己判断，规则和 `SanityGauge` 一样

### 3.4 切换时刻

| 时刻 | 做法 |
|---|---|
| 进入癫狂 | 音乐在下一拍静音（最多等 0.25 秒），空 1 拍，播乐句 S03「坠入」（深潮的呼吸，约 2 秒），然后叠夜层已经就位地回来。和双面牌翻面（0.3 秒）、墨从四角渗入（0.5 秒）同时开始 |
| 离开癫狂 | 一声倒放的长音（0.6 秒），叠夜层在这 0.6 秒里收掉 |
| 崩溃 | 0.3 秒内所有层推到最大并挤成一个音簇 → 和画面反相同一帧切成全静 → 0.6 秒后（裂纹淡出）回到理智 3 的配置 |
| 一次结算里理智连续变化 | 只跟最后的值；1 秒内癫狂进出来回，S03 只播一次 |

### 3.5 疯语低语

手里每有一张疯语，加一层耳语，最多 3 层。耳语是听不清的中文低语，偶尔能听清半个词。12 里疯语是「别的夜里的你在说话」。

这是幻听，但说的是真话：手里有疯语，回合结束就真的会扣理智（10 §6.2 的疯语预告是同一个信息）。疯语打出、消耗或弃掉，耳语立刻停。

### 3.6 保留音色

下面这些音色只用来表示对应的游戏信号。环境偶发层（§5.4）、事件底、曲子里的装饰都不许用，免得玩家把氛围当成「我掉理智了」：

- 失去理智的「掐灭灯芯」和下行钢琴音（R01）
- 恢复理智的玻璃清音（R02）
- 深潮的呼吸（S03）
- 潮钟（S02、B01、B02、Boss 潮位层）
- 疯语耳语（§3.5）、精神攻击的贴耳低语（R03）

## 5. 音效

### 5.1 原则

- **卡牌是纸**：旧纸、湿纸，和「墨与纸」的画面一致
- **打击要闷**：布、木头、湿的东西。不要金属的「叮」和电子感的冲击
- **短、干、定格**：对应版画「一拍二」的定格感；音效本身几乎不带混响，空间感交给环境层
- **不泄露意图**：敌人出招前的音效不按数值分档；命中以后的音效可以分档（这时数值已经公开）
- 倍速 2× / 3× 时音效不变调，只靠节流（§6.1）防止糊成一片

**R01 / R02 的音高**：D 弗里几亚从 D3 往上排，剩 0 理智 = D3，剩 4 = A3，剩 9 = F4，剩 10 = G4，上限超过 10 时往上接。连扣三格就连着往下走三个音，闭眼也能听出还剩多少、离癫狂线多近。剩 ≤ 4 时同一个音下面加一个水下的低八度，只当衬底（音量是主音的六成）。主音全在 145 Hz 以上，笔记本喇叭放得出来。R02 用同一个音阶，但高一个八度：玻璃在 D3 那么低的地方不像玻璃。R01 / R02 不加随机音高。

R01 里灯芯的嘶声比琴音早 30 ms 出声：两个起音错开，峰值就不会叠在一起（样张里叠在一起时峰值冲到 +1.8 dBFS）。

**来源判断**：R03、R05、R06 要知道这次理智损失从哪来。AudioDirector 看同一批事件里前一条叙述事件（敌人行动 / 回合开始 / 回合结束）判断；判断不了就退回 R01。

## 6. 技术方案

### 6.1 架构

| 部件 | 职责 |
|---|---|
| `AudioDirector`（`View/Audio/`） | 常驻单例。按当前界面选曲，管分轨音量和切换，读 `LunacyFx`，把战斗事件翻译成音效和音乐参数 |
| `SfxPlayer` | 16 个 AudioSource 的池；同一 ID 80 ms 内最多 2 个；随机挑变体，音高随机 ±3%（R01 / R02 除外） |
| `AudioDatabase` | ScriptableObject，ID → 片段、音量、变体。**没有素材的 ID 直接不出声、不报错**，和 ArtDatabase 没图就走灰盒一样，可以边做边接 |
| `MusicPiece` | 一首曲子的分轨、BPM、拍号、入口小节、各层规则 |

**接入点**

- 战斗：在 `BattleScreen.Apply` 开头加一行，把每条事件也交给 `AudioDirector`。BattleDirector 是逐条回放的，音效自然和画面对齐，倍速时一起变快
- 跑局：`RunScreen` 切面板时调 `AudioDirector.SetScene(场景, 层数, 精英 / 事件 ID)`
- 癫狂、潮水、深海之歌：读 `LunacyFx.Current`、`LunacyFx.Tide` 和深海之歌的状态，不另算一套。深海之歌现在只有 `SetSong`，要补一个读取的属性
- 清明：见 §3.3

**同步**

- 同一首的分轨用 `AudioSource.PlayScheduled(AudioSettings.dspTime + 0.1)` 同时起播，`loop = true`。分轨长度必须精确到采样一致
- 叠夜拷贝：同一个「主」片段，`PlayScheduled` 晚对应的延迟起播，`pitch` = 2^(音分 / 1200)
- 换曲在下一个小节线上交叉淡化；乐句在下一拍起播
- S02 的倒放：AudioListener 上挂一个 `OnAudioFilterRead`，一直保留最近 2 秒的混音输出，死亡时把这段反过来播

**测试**：PlayMode 测试检查 AudioDirector 的状态（理智从 10 打到 1 时各层的目标音量、换曲、节流、没有素材时不报错），不靠耳朵。音频文件用脚本检查循环接缝（首尾采样差、RMS 跳变）和响度。

### 6.2 混音器

```
Master
├─ Music              ← 音乐音量
│  ├─ Stems           ← 底 / 主 / 清明 / 曲目专属
│  ├─ Nights          ← 叠夜 1–4：低通、混响送量由理智驱动（§3.3）
│  └─ Deep            ← 深渊层
├─ Ambience           ← 环境底、偶发层
├─ SFX                ← 音效音量
│  ├─ UI
│  ├─ Combat
│  └─ Sanity          ← R 系列。发 Duck 信号：Music −4 dB、Ambience −6 dB，起 20 ms、放 300 ms
└─ Reverb（返回）      ← Stems / Nights / Ambience 按送量发过来；返回电平校准到响度增益 0 dB（§3.3）
```

Music 组的音量 = 玩家的音乐音量 + §3.3 的「音乐总线补偿」。

- 暴露参数：`NightsCutoff`、`MainCutoff`、`ReverbSend`、`DeepLevel`，以及四个音量
- 快照：正常 / 暂停（Music 和 Ambience 低通到 1.2 kHz、−6 dB）/ 结算
- 镜中倒影事件：Master 临时挂一个 Echo，延迟 0.4 秒、无反馈、湿 50%

### 6.3 格式与响度

| 项 | 规格 |
|---|---|
| 源文件 | 48 kHz / 24 bit WAV，放 `Deeptide/AudioSource/`（Assets 外面，走 LFS，`.gitattributes` 里 `.wav` `.ogg` 已经是 LFS） |
| 音乐分轨 | Vorbis 质量 0.6；Compressed In Memory（叠夜要同一个片段开好几个 AudioSource，Streaming 每个都要单开一路流） |
| 单轨曲（标题、篝火、事件底） | Vorbis 0.6，Streaming |
| 短音效（< 1 秒） | Decompress On Load，ADPCM |
| 乐句、长音效 | Compressed In Memory，Vorbis 0.7 |
| 响度 | 一首曲子所有分轨全开时约 −23 LUFS（主机 / PC 常用 −24 ± 2）；理智音效比同时刻的音乐高 6 dB 以上；真峰值 ≤ −1 dBTP |
| 低频 | 深渊层以 30–60 Hz 为主，30 Hz 以下切掉（耳机里久听会累，喇叭也放不出）。**承载信息的声音不放在 120 Hz 以下**，笔记本喇叭听不到 |
| 立体声 | 全部单声道兼容，不用反相做宽度 |
| 循环 | 循环点在小节线；混响尾巴预先折回循环开头 |
| 体积 | 全部音频约 100 MB（音乐分轨合计约 75 分钟；叠夜不占存储）。底、深渊这类没有声像的分轨用单声道，能再省三成 |

### 7.2 生产路线

路线 E 做不好的：有表情的独奏弦乐长旋律、真实的合唱、钢琴的细腻力度。这几处用 CC0 采样回放，写法上也简单一点（长音、拨弦、短句）；还不够就那一首走 C。

**建议**：E 为主，A 补真实录音，人声自己录。和美术一样，先做 §7.4 的样张三件套，听过再决定 Boss 和标题要不要换 C。
