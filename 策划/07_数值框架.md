# 07 数值框架

> 所有数值都是**初版假设**，用来让设计在逻辑上自洽、能直接开工。最终以模拟器和试玩数据为准。

## 1. 价值换算表（能量当量 E）

以「1 能量」为通用货币，基准是：打击（6 伤害）= 1E，防御（5 格挡）= 1E。

| 单位 | 当量 | 备注 |
|---|---|---|
| 1 能量 | 1.0E | |
| 1 点单体伤害 | 0.167E | 6 伤害 = 1E |
| 1 点全体伤害 | 0.13E | 按单体的 0.8 倍算（平均 2–3 个敌人，但常有溢出伤害） |
| 1 点格挡 | 0.2E | 5 格挡 = 1E；超出来袭伤害的部分不计价 |
| 抽 1 张牌 | 0.5E | |
| 易伤 / 虚弱 1 层 | 0.3E | |
| 力量 1（本场） | 0.6E | 多段攻击的构筑里更高 |
| 1 点生命 | 0.15E | |
| 心防 1 层 | 0.6E | 约等于挡掉 1–2 点敌方理智伤害 |
| 1 点恐惧 | 0.2E（普通敌人）/ 0.1E（精英、Boss） | 震慑一个意志 8 的敌人 ≈ 跳过约 10 伤害 ≈ 1.6–2E |
| **1 点理智** | **有方向，见 §2** | |

## 2. 理智的定价（有方向）

理智的价值取决于**构筑方向**和**当前所处区间**：

| 区间 | 守夜视角 | 堕落视角 | 理由 |
|---|---|---|---|
| 清醒区（5–上限） | −0.5E / 点 | −0.1E / 点（接近免费） | 守夜流要花资源补回来；堕落流反正要往下走 |
| 癫狂区（1–4） | −0.5E / 点 | −0.8E / 点 | 越靠近 0，崩溃（约 7 生命 + 永久诅咒 ≈ 3E 以上）的风险越大 |
| 恢复 1 点 | +0.5E | +0.1E | 满理智时的溢出只对「圣痕」等有价值 |

推论：**同一张带代价的牌，在两种构筑里的价值不同**（见 §4 中「坠落」的例子）。这是理智系统让抓牌决策变得有深度的根源，后续设计要主动保持这种差异。

## 3. 稀有度效率区间

| 稀有度 | 效率（E 产出 / 能量消耗） | 说明 |
|---|---|---|
| 基础 | 1.0 | 打击、防御 |
| 普通 | 1.2–1.5 | 单一效果，或带简单条件 |
| 罕见 | 1.5–1.8，或带构筑机制 | 能力牌按 5 回合的期望收益折算 |
| 稀有 | 不严格要求 | 构筑核心，能改变打法 |

- **双面牌**：癫狂面的收益（扣除副作用之前）= 清醒面 × 1.6–1.8；扣除副作用后净值约为 1.4–1.6 倍
- **升级**：只改一个维度，带来约 +30–50% 的价值，或者 −1 费，或者去掉「消耗」
- **0 费牌**：按 0.5E 的隐性成本估价（占用一个抽牌位置）

## 4. 校验示例

数值是 2026-10-18 调参之后的版本（§8）。

| 卡 | 计算 | 效率 | 结论 |
|---|---|---|---|
| 打击 | 6 伤害 = 1.0E ÷ 1 | 1.0 | 基准 |
| 祷告 | 6 格挡 1.2 + 恢复 1 理智 0.5 = 1.7 ÷ 1 | 1.7（满理智时 1.2） | 期望约 1.4，普通区间内 ✓ |
| 梦魇之刃（清醒） | 8 伤害 = 1.33 ÷ 1 | 1.33 | ✓ |

| 坠落 | +1E + 抽 1 0.5 − 2 理智 | 守夜 0.5 / 堕落 1.3（0 费） | 价值随方向反转 ✓ |

## 5. 战斗与跑局目标区间

### 5.1 单场战斗

| 战斗 | 敌方总生命 | 敌方每回合输出 | 期望回合数 | 期望掉血（熟练玩家中位数） |
|---|---|---|---|---|
| 简单池（前 3 场） | 40–50 | 6–11 | 3–4 | 2–6 |
| 困难池 | 55–80 | 10–16 | 4–6 | 4–9 |
| 精英 | 84–114 | 12–20 | 5–7（堕落可以更快） | 10–22 |
| Boss | 180（2026-10-18 由 240 下调，§8.2） | 15–30（大潮 20 / 28） | 7–10 | 30–45 |

> 精英、Boss 的回合目标原来是 6–8 / 10–14，2026-10-18 下调（§8.5）：侵蚀从第 4 回合开始每回合 −1 理智，Boss 第二阶段再加深海之歌 −1，一场 12 回合的 Boss 战至少要多付十几点理智，任何流派都扛不住。回合数的上限是理智规则本身定的，不是敌人数值

### 5.2 生命账本（熟练玩家，中位数）

| 项 | 生命 |
|---|---|
| 起始 | 70 |
| 简单池 3 场 × 4 | −12 |
| 困难池 5 场 × 6.5 | −33 |
| 精英 2 场 × 16 | −32 |
| 篝火休息 2 次（含第 15 层） | +42 |
| 事件 / 遗物回复 | +8 |
| **到达 Boss 时** | **≈ 43（目标 40–50）** |

Boss 期望掉血 30–45，所以熟练玩家的 Boss 战胜率大约一半，同时能明显感觉到「路线规划」和「篝火是休息还是锻造」这些选择的分量。

### 5.3 整体目标

| 指标 | 目标 |
|---|---|
| 单局时长 | 35–50 分钟 |
| 首通率（熟练的尖塔玩家） | 40–60% |
| 首通率（新手） | 10–25% |
| 三个流派的胜率差 | ≤ 10 个百分点 |
| 进入过癫狂的战斗占比 | 40–70%（说明机制真的被用上了） |
| 堕落构筑每场崩溃次数 | 0.3–0.8（有，但不常态化） |
| 守夜构筑的清明回合占比 | ≥ 50% |
| 每张非基础牌的拾取率 | 10–60%（太高说明是必选，太低说明是废卡） |

## 6. 调参流程

```
改 Data/*.csv ──▶ 无头模拟器批量跑 ──▶ 对照 §5 目标区间 ──▶ 不达标就回到第一步
                                         │ 达标
                                         ▼
                                  阶段末试玩（3–5 人）+ 遥测 ──▶ 回到第一步
```

### 6.1 无头模拟器

- 战斗内核是纯 C#（见 [08](08_技术方案.md)），可以在 Unity 之外用 `dotnet` 直接跑
- **战斗 AI**：每回合开始时复制一份战斗，对这一回合的出牌顺序做束搜索（束宽 6、最多 8 张），评分 = 敌方生命、格挡、理智（按流派定方向）、自身生命、能力、恐惧的加权和
- **跑局 AI**：规则选牌（流派偏好 + 卡牌强弱表）、选路、商店、篝火、事件、药水（用法见 `Tools/README.md`）
- **用法**：`batch` 指定牌组 × 遭遇组合；`runbatch` 每个流派跑 1000 局整局，输出 §5.2 的生命账本和 §5.3 的指标
- **局限**：战斗 AI 预演时看得到真实抽牌（相当于知道牌序），「何时坠落」的判断却比人保守；跑局 AI 的构筑比熟练玩家差。所以**相对比较**（改动前后、流派之间）比绝对值可靠

### 6.2 试玩遥测（每局一个 JSON）

| 层级 | 字段 |
|---|---|
| 局 | 版本、种子、到达层数、胜负、死因、用时、最终牌组、遗物 |
| 节点 | 层、类型、进入时生命、金币 |
| 战斗 | 遭遇 ID、回合数、掉血、理智最低值、崩溃次数、癫狂回合数、每张牌打出次数 |
| 奖励 | 提供的选项、选中的选项（含跳过） |

**实现（2026-10-25）**：
- 内核：`RunStats.Nodes` 每个节点一条（层、房间、进入时的生命 / 金币 / 累计用时、遭遇或事件 ID、奖励列表或商店货架、在这里做的每个选择），`RunTelemetry.From` 把一局摘成上表的字段。牌组里的选择记成 `remove:卡牌` / `upgrade:卡牌`，不记下标。这些都不参与规则和哈希
- 游戏：每次存档顺带写 `persistentDataPath/telemetry/开局时间_种子.json`，同一局一直覆盖同一个文件（结果从「没打完」变成通关 / 倒下 / 放弃），中途关游戏也留得下。只写本机，不联网。用时按游戏窗口在前台、3 分钟内有鼠标键盘操作的时间算。流派按最终牌组里守夜 / 堕落 / 传染牌的数量粗分（一类过半且 ≥ 3 张，否则算混合）
- 汇总：`deeptide-sim telemetry --dir 文件夹`，口径和 `runbatch` 相同（见 `Tools/README.md`）。`runbatch --telemetry 目录` 能把 AI 局写成同样的文件，真人和 AI 放在一起对照
- 试玩包：菜单「Deeptide → 打包 Windows」，包里带 `试玩说明.txt`（玩法简介、怎么把记录发回来、5 个问题），见 [09 §5.2](09_开发计划.md)「本机并行：试玩包」

## 7. 模拟调参记录（2026-10-17）

### 7.1 方法

- 工具：`Tools/Deeptide.Sim` 的 `tune` 模式，在参数网格上跑遍全部对局组合，按下表打分（越低越好），前几名再用 500–1000 场复核。所有参数共用同一组种子 1..n，减少比较时的噪声
- 评估口径：**遭遇 1 是第一层的战斗，用起始牌组衡量；遭遇 2、3 属于困难池，用 A/B/C 三套中期牌组衡量**。起始牌组也会去打遭遇 2、3，只要求能赢、不频繁崩溃
- AI：一步贪心，会优先击杀能做精神攻击的敌人。如果没有这条，起始牌组打呓语者时每场会崩溃约 1.5 次，几乎全部是 AI 不会集火造成的假象

| 扣分项 | 目标 | 权重 |
|---|---|---|
| 回合数 | 起始牌组打遭遇 1：3–4；中期牌组打困难池：4–6 | 每超出 1 回合 2.0 |
| 掉血 | 起始牌组打遭遇 1：2–6；中期牌组打困难池：4–9 | 每超出 1 点 0.5 |
| 胜率 | 中期牌组 ≥ 90%；起始牌组打遭遇 1 ≥ 95%，打困难池 ≥ 80% | 每差 1% 扣 0.2 |
| 起始牌组崩溃 | 打困难池 ≤ 0.5 次 / 场 | ×4 |
| 守夜清明 | A 组清明回合占比 ≥ 50% | ×10 |
| 堕落入癫 / 崩溃 | B 组进入癫狂 ≥ 80%；崩溃 0.3–0.8 次 / 场 | ×5 / ×2 |
| 混合入癫 | C 组进入癫狂的战斗占 30–70% | ×5 |
| 两条路差距 | C 组用「保持清醒」和「主动坠落」两种 AI 打法的掉血差 | ×0.5 |
| 整体入癫 | 中期牌组进入癫狂的战斗占 40–70% | ×5 |

### 7.2 搜索范围与结论

共试了约 130 组参数：

| 参数 | 试过的值 | 结论 |
|---|---|---|
| 侵蚀起始回合 | 3 / 4 / 5 | **保持 4**。改成 3 的组合在第一轮里都没进前列；改成 5 时总分接近，但堕落 / 混合组进入癫狂的比例下降（93% → 84%、30% → 19%），理智压力变弱 |
| 癫狂线 | 4 / 5 | **保持 4**。改成 5 后守夜组被动进入癫狂的比例从 13% 升到 21%，总分变差 |
| 起始牌组 | 防御 ×4 / 祷告换 1 张防御 | **用 1 张祷告换掉 1 张防御**。每一轮的前几名都是这个选项：开局就有回复理智的手段，起始牌组进困难池时不再频繁崩溃 |
| 崩坏边缘每点加成 | 2 / 3 | **保持 2**。改成 3 没有明显收益，单卡效率反而远超罕见卡的区间 |
| 明理之刃倍率 | 2 / 3 | **保持 3** |
| 祷告回复 | 1 / 2 | **保持 1**。改成 2 守夜清明能达标，但混合组两条路的差距会拉大，总分相同 |
| 困难池生命 | ×1.0–1.45；按敌人逐个试 | **呓语者 18–22 → 23–27**，失魂镇民保持不变。镇民加血会让遭遇 3 的掉血超出目标 |

### 7.3 调整前后对比（共用种子；调整前 500 场、调整后 1000 场复核）

| 指标 | 调整前 | 调整后 | 目标 |
|---|---|---|---|
| 总分 | 8.89 | **7.18** | 越低越好 |
| 起始牌组打遭遇 1：回合 / 掉血 | 4.0 / 6.3 | 4.0 / 5.4 | 3–4 / 2–6 |
| 困难池回合 A / B / C | 4.5 / 3.4 / 3.3 | 4.6 / 3.5 / 3.5 | 4–6 |
| 困难池掉血 A / B / C | 6.6 / 7.7 / 8.0 | 6.4 / 7.5 / 7.6 | 4–9 |
| 进入癫狂 A / B / C | 5% / 74% / 20% | 3% / 81% / 19% | — / ≥ 80% / 30–70% |
| A 组清明回合占比 | 43% | 44% | ≥ 50% |
| C 组清醒 / 坠落两种打法的掉血 | 8.3 / 8.4 | 8.0 / 8.5 | 差距越小越好 |

两种打法的掉血差不到 1 点，说明在混合牌组里「保持清醒」和「主动坠落」都是可行的路线，坠落并不是稳亏。

### 7.4 遗留问题（阶段 3 补全内容后再调）

- **中期牌组打困难池偏快**（B、C 约 3.5 回合，目标 4–6）。单纯加敌人血量会让掉血超标，需要「加血 + 降伤害」一起调，属于敌人内容调整
- **遭遇 3 里堕落牌组掉血 10.6**，略超目标。这正是「嗅到疯狂」想要的惩罚效果，先保留，等精英和遗物加入后再看
- **混合组入癫 19%、守夜清明 44%**，都略低于目标；AI 的坠落判断比真人保守，需要纸面试玩确认
- AI 是一步贪心，只适合做相对比较；改动前后的差值比绝对值可靠

### 7.5 第二轮：按试玩反馈修改（2026-10-17）

[试玩记录](../原型/试玩记录_2026-10-17.md) 里发现了 3 个模拟器量不出来的问题，逐个修改并用模拟器验证：

| # | 问题 | 修改 | 验证 |
|---|---|---|---|
| 1 | 「清明 = 满理智」太苛刻，守夜流的清明效果经常一次都触发不了 | **清明改为理智 ≥ 上限 − 1**（`BattleConfig.ClarityMargin = 1`） | 在余量 0 / 1 / 2 × 祷告回复 1 / 2 上搜索：余量 1 时守夜清明回合占比 43% → **63%**，达到目标；余量 2 是 72%，但总分没有更好，所以取改动更小的 1。祷告回复保持 1 |
| 2 | 意图模糊对只有一种攻击的敌人无效：知道是「攻击」就等于知道数值 | **每个敌人加一招同类型、数值不同的变体**：侍僧「献祭重击」11（匕首调为 6），呓语者「尖啸」精神攻击 3，镇民「猛砸」12。权重改成六面骰的面数，纸面原型可以直接掷骰 | 搜索了匕首 6 / 7、重击 10 / 11、猛砸 12 / 14：猛砸 14 会让遭遇 3 掉血超标；侍僧几组数值的差距在噪声范围内，取总分最高的 6 / 11 |
| 3 | 调查笔记在敌人回合触发时，+1 能量会被回合开始的能量重置吞掉 | **敌人回合中获得的能量顺延到下回合**（通用规则，不只对调查笔记） | 单元测试覆盖：被精神攻击推入癫狂后，下回合能量为 4，手牌为 7 |

**模拟器同步改进**：AI 现在遵守意图模糊。癫狂时它只知道意图类型，按该敌人同类型招式的平均值估计伤害，不再偷看真实数值。

**前后对比**（同一个 AI、共用种子、各 1000 场；「修改前」用的是清明必须满理智、同类招式数值相同的设置）：

| 指标 | 修改前 | 修改后 | 目标 |
|---|---|---|---|
| 总分 | 6.09 | **5.77** | 越低越好 |
| 起始牌组打遭遇 1：回合 / 掉血 | 4.0 / 5.5 | 4.2 / 4.7 | 3–4 / 2–6 |
| 困难池回合 A / B / C | 4.6 / 3.4 / 3.5 | 4.6 / 3.5 / 3.5 | 4–6 |
| 困难池掉血 A / B / C | 6.2 / 6.4 / 6.9 | 6.5 / 6.8 / 7.2 | 4–9 |
| 进入癫狂 A / B / C | 4% / 83% / 23% | 4% / 84% / 25% | — / ≥ 80% / 30–70% |
| **A 组清明回合占比** | **43%** | **63%** | ≥ 50% |
| C 组清醒 / 坠落两种打法的掉血 | 7.3 / 7.6 | 8.2 / 8.0 | 差距越小越好 |

**关于意图模糊，一个需要如实记下的结论**：用调试开关（`--peek 1`）让 AI 在癫狂时偷看真实意图，结果和遵守模糊时**几乎完全一样**。原因是现在的战斗太短，癫狂回合只占 2–14%，看不清对决策的影响很小。攻击变体修好了「看招式表就能猜出数值」的漏洞，让真人玩家在癫狂时确实面对不确定性；但要让模糊在数值上真正有分量，需要更长的战斗和更多癫狂回合。这和 §7.4 的「战斗偏短」是同一个根本问题，留到阶段 3 一起处理。

## 8. 内容补齐后的调参（2026-10-18）

### 8.1 单场（M3.6）

**方法**：`batch` 按遭遇汇总。起始牌组打简单池，A / B / C / D 四套中期牌组（D 是新增的传染牌组）打困难池和精英，每组 150–200 场，迭代三轮。

| 对象 | 修改 |
|---|---|

### 8.5 四个待定项的决定（2026-10-18）

### 8.6 心智崩塌改为打完清空恐惧（2026-10-26）

**问题**：朋友试玩 8 局的遥测里，带心智崩塌的 3 局全部通关，没带的 3 局全倒（另外 2 局开局就放弃了）。带它的 3 场 Boss 战是 5 / 6 / 8 回合、掉血 0 / 23 / 26，低于 §5.1 的 7–10 回合、30–45 掉血。原来不清空恐惧，Boss 意志 30，叠恐惧时只要不震慑，恐惧就能一直停在二十几点，每抽到一次就打 80–116。§4 写的风险控制是「震慑会清空恐惧」，叠恐惧时不去震慑就绕过去了。

**修改**：打出后清空目标的恐惧。不算震慑，意志不涨。倍率不变（×4，升级 ×5）。

**模拟**（`runbatch` 每个流派 1000 局；`batch` 用 D 牌组打 Boss 300 场；`--set` 只改未升级版，升级版一律 ×5）：

| 方案 | 传染胜率 | 混合胜率 | D 打 Boss 胜率 |
|---|---|---|---|
| 原版：不清空 ×4 | 26.6% | 31.0% | 57% |
| 不清空 ×3（§8.2 加强前） | 19.7% | 29.3% | 40% |
| 恐惧减半 ×4 / ×5 | 17.1% / 21.8% | 29.9% / 30.0% | 41% / 56% |
| **清空 ×4（采用）** | **11.6%** | **28.9%** | **19%** |
| 清空 ×5 / ×6 | 15.7% / 21.1% | 28.8% / 30.1% | 40% / 51% |
| 清空 ×4 + 保留 | 10.6% | 29.5% | 20% |

同一组种子下守夜 21.0%、堕落 27.7%。

**模拟的跌幅偏大**：战斗 AI 只看当前这一回合，抽到心智崩塌就打。Boss 战日志里打出时目标恐惧只有 2–7，有一次还是先打崩塌、后施加恐惧。清空之后这样打最亏。真人会先叠恐惧再兑现，单次还是 ×4 的二十几点恐惧，只是不能反复打。所以表里的数字只代表「抽到就打」的玩家，量不出真人打传染有多强。加「保留」对 AI 也没用，原因相同。

**下一步**：下一轮试玩看传染局的 Boss 回合数和胜率。如果明显打不过，先试 ×5（升级 ×6），再考虑加「保留」，让玩家自己挑兑现的时机。


### 8.7 狼人第一轮调参（M6.4，2026-10-27）

**跑局 AI**：加了狼人的三个流派（`--arch hunt,moon,feast`，`--char werewolf` 时默认跑这三个加混合）：按流派给牌加分（血宴是桥梁，另外两个流派拿血宴牌也加一点）、30 张牌的强弱表、遗物按「狂猎 / 月相 / 血宴」倾向匹配；事件和篝火护理智上限（禁书只烧、不照镜子偷病历、理智上限低于 6 就静思 / 惊醒）。战斗打法：狂猎用堕落的打法（往下走、常驻兽形），月相、血宴用混合。战斗 AI 的估值加了流血（剩余总伤害按八成算）；变身 / 复归、兽形 +2、格挡减半不用单独教，束搜索在复制出的战斗上预演，自己就看得到「先复归再挡」。

**结果**（`runbatch` 1000 局，种子 1..1000）：

| | 狂猎 | 月相 | 血宴 | 混合 | 三个流派平均 |
|---|---|---|---|---|---|
| 调整前（压抑兽性 1 费） | 28.7% | 13.3% | 30.0% | 22.7% | 24.0%（300 局） |
| **压抑兽性改 0 费（采用）** | **28.6%** | **25.4%** | **30.2%** | **21.8%** | **28.1%** |
| 同时狼牙吊坠复归格挡 4 → 6 | 32.6% | 33.8% | 35.2% | 24.8% | 33.9%（500 局，没采用：比调查员高太多） |
| 调查员（同一组种子） | 守夜 18.5% | 堕落 26.0% | 传染 11.6% | 28.9% | 18.7% |

- 只改了一处：**压抑兽性 1 费 → 0 费**。月相缺的是「跨线」本身的成本：一回合要一张往下、一张往上的牌，往上的那张 1 费、只回 2 理智，跨线之后的触发（吊坠、狂性、双相）补不回来。0 费以后月相 15% → 25%，其余流派基本不动。0 费不给能量，抽牌只在本轮第一次复归时触发，没有循环
- 14 §8 的指标：狼人和调查员胜率差，三个流派平均 9.4 个百分点、连混合四个一起平均 5.3（目标 ≤ 10，贴着上限，主要因为调查员的传染在 §8.6 之后只有 11.6%）；狼人三个流派之间 4.8，含混合 8.4（≤ 10）；兽形回合占比 37–49%（30–70%）；每场变身 + 复归：月相 3.3，狂猎 1.3、血宴 1.5、混合 1.4
- **决定：「变身 + 复归 ≥ 3」只考月相**。狂猎的设计就是常驻兽形，血宴不在乎形态，它们跨线少是对的；改成「月相 ≥ 3，其余流派不设下限」，写进 14 §8
- 狼人的「进入过癫狂的战斗」77–89%，超出 §5.3 的 40–70%：那是给调查员定的（衡量「机制有没有被用上」），狼人本来就住在线上，不适用
- 精英掉血：狼人 16–18，调查员 16–20，M6.3 时贪心 AI 看到的「狼人打精英明显偏弱」是跑局 AI 不会选狼人牌造成的，换成会选牌的 AI 后就没有了
- 遗留：狼人比调查员略强，是不是要回调等 6.7 真人试玩；调查员三流派差 14.4 个百分点（传染偏弱），按 §8.6 的「下一步」处理，和狼人无关
