# 07 数值框架

> 所有数值都是**初版假设**，用来让设计在逻辑上自洽、能直接开工。最终以模拟器和试玩数据为准。

## 1. 价值换算表（能量当量 E）

以「1 能量」为通用货币，基准是：打击（6 伤害）= 1E，防御（5 格挡）= 1E。

| 单位 | 当量 | 备注 |
|---|---|---|
| 1 能量 | 1.0E | |
| 1 点单体伤害 | 0.167E | 6 伤害 = 1E |
| 1 点全体伤害 | 0.13E | 按单体的 0.8 倍算（平均 2–3 个敌人，但常有溢出伤害） |
| 1 点格挡 | 0.2E | 5 格挡 = 1E；超出来袭伤害的部分不计价 |
| 抽 1 张牌 | 0.5E | |
| 易伤 / 虚弱 1 层 | 0.3E | |
| 力量 1（本场） | 0.6E | 多段攻击的构筑里更高 |
| 1 点生命 | 0.15E | |
| 心防 1 层 | 0.6E | 约等于挡掉 1–2 点敌方理智伤害 |
| 1 点恐惧 | 0.2E（普通敌人）/ 0.1E（精英、Boss） | 震慑一个意志 8 的敌人 ≈ 跳过约 10 伤害 ≈ 1.6–2E |
| **1 点理智** | **有方向，见 §2** | |

## 2. 理智的定价（有方向）

理智的价值取决于**构筑方向**和**当前所处区间**：

| 区间 | 守夜视角 | 堕落视角 | 理由 |
|---|---|---|---|
| 清醒区（5–上限） | −0.5E / 点 | −0.1E / 点（接近免费） | 守夜流要花资源补回来；堕落流反正要往下走 |
| 癫狂区（1–4） | −0.5E / 点 | −0.8E / 点 | 越靠近 0，崩溃（约 7 生命 + 永久诅咒 ≈ 3E 以上）的风险越大 |
| 恢复 1 点 | +0.5E | +0.1E | 满理智时的溢出只对「圣痕」等有价值 |

推论：**同一张带代价的牌，在两种构筑里的价值不同**（见 §4 中「坠落」的例子）。这是理智系统让抓牌决策变得有深度的根源，后续设计要主动保持这种差异。

## 3. 稀有度效率区间

| 稀有度 | 效率（E 产出 / 能量消耗） | 说明 |
|---|---|---|
| 基础 | 1.0 | 打击、防御 |
| 普通 | 1.2–1.5 | 单一效果，或带简单条件 |
| 罕见 | 1.5–1.8，或带构筑机制 | 能力牌按 5 回合的期望收益折算 |
| 稀有 | 不严格要求 | 构筑核心，能改变打法 |

- **双面牌**：癫狂面的收益（扣除副作用之前）= 清醒面 × 1.6–1.8；扣除副作用后净值约为 1.4–1.6 倍
- **升级**：只改一个维度，带来约 +30–50% 的价值，或者 −1 费，或者去掉「消耗」
- **0 费牌**：按 0.5E 的隐性成本估价（占用一个抽牌位置）

## 4. 校验示例

| 卡 | 计算 | 效率 | 结论 |
|---|---|---|---|
| 打击 | 6 伤害 = 1.0E ÷ 1 | 1.0 | 基准 |
| 祷告 | 6 格挡 1.2 + 恢复 1 理智 0.5 = 1.7 ÷ 1 | 1.7（满理智时 1.2） | 期望约 1.4，普通区间内 ✓ |
| 梦魇之刃（清醒） | 8 伤害 = 1.33 ÷ 1 | 1.33 | ✓ |
| 梦魇之刃（癫狂） | 14 伤害 2.33 − 2 生命 0.3 = 2.03 | 2.03 | 收益 14/8 = 1.75 倍 ✓ |
| 坠落 | +1E + 抽 1 0.5 − 2 理智 | 守夜 0.5 / 堕落 1.3（0 费） | 价值随方向反转 ✓ |
| 恐怖低语 | 4 恐惧 0.8 + 抽 1 0.5 = 1.3 ÷ 1 | 1.3 | ✓（打精英时 0.9） |
| 驱散 | 15 伤害 2.5 ÷ 2 / 清明 24 伤害 4.0 ÷ 2 | 1.25 / 2.0 | 清明奖励幅度够大 ✓ |
| 明理之刃 | 理智 10：30 伤害 5.0 ÷ 2；理智 6：18 伤害 3.0 ÷ 2 | 2.5 / 1.5 | 稀有、条件强 ✓ |

## 5. 战斗与跑局目标区间

### 5.1 单场战斗

| 战斗 | 敌方总生命 | 敌方每回合输出 | 期望回合数 | 期望掉血（熟练玩家中位数） |
|---|---|---|---|---|
| 简单池（前 3 场） | 40–50 | 6–11 | 3–4 | 2–6 |
| 困难池 | 55–80 | 10–16 | 4–6 | 4–9 |
| 精英 | 70–95 | 12–20 | 6–8 | 10–22 |
| Boss | 240 | 15–30（大潮 28 / 36） | 10–14 | 30–45 |

### 5.2 生命账本（熟练玩家，中位数）

| 项 | 生命 |
|---|---|
| 起始 | 70 |
| 简单池 3 场 × 4 | −12 |
| 困难池 5 场 × 6.5 | −33 |
| 精英 2 场 × 16 | −32 |
| 篝火休息 2 次（含第 15 层） | +42 |
| 事件 / 遗物回复 | +8 |
| **到达 Boss 时** | **≈ 43（目标 40–50）** |

Boss 期望掉血 30–45，所以熟练玩家的 Boss 战胜率大约一半，同时能明显感觉到「路线规划」和「篝火是休息还是锻造」这些选择的分量。

### 5.3 整体目标

| 指标 | 目标 |
|---|---|
| 单局时长 | 35–50 分钟 |
| 首通率（熟练的尖塔玩家） | 40–60% |
| 首通率（新手） | 10–25% |
| 三个流派的胜率差 | ≤ 10 个百分点 |
| 进入过癫狂的战斗占比 | 40–70%（说明机制真的被用上了） |
| 堕落构筑每场崩溃次数 | 0.3–0.8（有，但不常态化） |
| 守夜构筑的清明回合占比 | ≥ 50% |
| 每张非基础牌的拾取率 | 10–60%（太高说明是必选，太低说明是废卡） |

## 6. 调参流程

```
改 Data/*.csv ──▶ 无头模拟器批量跑 ──▶ 对照 §5 目标区间 ──▶ 不达标就回到第一步
                                         │ 达标
                                         ▼
                                  阶段末试玩（3–5 人）+ 遥测 ──▶ 回到第一步
```

### 6.1 无头模拟器

- 战斗内核是纯 C#（见 [08](08_技术方案.md)），可以在 Unity 之外用 `dotnet` 直接跑
- **AI**：每回合对手牌做束搜索（beam = 32），评分 = 伤害 × w₁ + 有效格挡 × w₂ − 理智损失 × w₃(按流派) − 生命损失 × w₄
- **用法**：指定牌组 × 遭遇组合，各跑 1000 次，输出掉血分布、回合数、崩溃次数、癫狂回合占比
- **局限**：模拟 AI 的「何时坠落」判断远不如人，所以**相对比较**（改动前后、A 卡对比 B 卡）比绝对值可靠

### 6.2 试玩遥测（每局一个 JSON）

| 层级 | 字段 |
|---|---|
| 局 | 版本、种子、到达层数、胜负、死因、用时、最终牌组、遗物 |
| 节点 | 层、类型、进入时生命、金币 |
| 战斗 | 遭遇 ID、回合数、掉血、理智最低值、崩溃次数、癫狂回合数、每张牌打出次数 |
| 奖励 | 提供的选项、选中的选项（含跳过） |

## 7. 模拟调参记录（2026-10-17）

### 7.1 方法

- 工具：`Tools/Deeptide.Sim` 的 `tune` 模式，在参数网格上跑遍全部对局组合，按下表打分（越低越好），前几名再用 500–1000 场复核。所有参数共用同一组种子 1..n，减少比较时的噪声
- 评估口径：**遭遇 1 是第一层的战斗，用起始牌组衡量；遭遇 2、3 属于困难池，用 A/B/C 三套中期牌组衡量**。起始牌组也会去打遭遇 2、3，只要求能赢、不频繁崩溃
- AI：一步贪心，会优先击杀能做精神攻击的敌人。如果没有这条，起始牌组打呓语者时每场会崩溃约 1.5 次，几乎全部是 AI 不会集火造成的假象

| 扣分项 | 目标 | 权重 |
|---|---|---|
| 回合数 | 起始牌组打遭遇 1：3–4；中期牌组打困难池：4–6 | 每超出 1 回合 2.0 |
| 掉血 | 起始牌组打遭遇 1：2–6；中期牌组打困难池：4–9 | 每超出 1 点 0.5 |
| 胜率 | 中期牌组 ≥ 90%；起始牌组打遭遇 1 ≥ 95%，打困难池 ≥ 80% | 每差 1% 扣 0.2 |
| 起始牌组崩溃 | 打困难池 ≤ 0.5 次 / 场 | ×4 |
| 守夜清明 | A 组清明回合占比 ≥ 50% | ×10 |
| 堕落入癫 / 崩溃 | B 组进入癫狂 ≥ 80%；崩溃 0.3–0.8 次 / 场 | ×5 / ×2 |
| 混合入癫 | C 组进入癫狂的战斗占 30–70% | ×5 |
| 两条路差距 | C 组用「保持清醒」和「主动坠落」两种 AI 打法的掉血差 | ×0.5 |
| 整体入癫 | 中期牌组进入癫狂的战斗占 40–70% | ×5 |

### 7.2 搜索范围与结论

共试了约 130 组参数：

| 参数 | 试过的值 | 结论 |
|---|---|---|
| 侵蚀起始回合 | 3 / 4 / 5 | **保持 4**。改成 3 的组合在第一轮里都没进前列；改成 5 时总分接近，但堕落 / 混合组进入癫狂的比例下降（93% → 84%、30% → 19%），理智压力变弱 |
| 癫狂线 | 4 / 5 | **保持 4**。改成 5 后守夜组被动进入癫狂的比例从 13% 升到 21%，总分变差 |
| 起始牌组 | 防御 ×4 / 祷告换 1 张防御 | **用 1 张祷告换掉 1 张防御**。每一轮的前几名都是这个选项：开局就有回复理智的手段，起始牌组进困难池时不再频繁崩溃 |
| 崩坏边缘每点加成 | 2 / 3 | **保持 2**。改成 3 没有明显收益，单卡效率反而远超罕见卡的区间 |
| 明理之刃倍率 | 2 / 3 | **保持 3** |
| 祷告回复 | 1 / 2 | **保持 1**。改成 2 守夜清明能达标，但混合组两条路的差距会拉大，总分相同 |
| 困难池生命 | ×1.0–1.45；按敌人逐个试 | **呓语者 18–22 → 23–27**，失魂镇民保持不变。镇民加血会让遭遇 3 的掉血超出目标 |

### 7.3 调整前后对比（共用种子；调整前 500 场、调整后 1000 场复核）

| 指标 | 调整前 | 调整后 | 目标 |
|---|---|---|---|
| 总分 | 8.89 | **7.18** | 越低越好 |
| 起始牌组打遭遇 1：回合 / 掉血 | 4.0 / 6.3 | 4.0 / 5.4 | 3–4 / 2–6 |
| 困难池回合 A / B / C | 4.5 / 3.4 / 3.3 | 4.6 / 3.5 / 3.5 | 4–6 |
| 困难池掉血 A / B / C | 6.6 / 7.7 / 8.0 | 6.4 / 7.5 / 7.6 | 4–9 |
| 进入癫狂 A / B / C | 5% / 74% / 20% | 3% / 81% / 19% | — / ≥ 80% / 30–70% |
| A 组清明回合占比 | 43% | 44% | ≥ 50% |
| C 组清醒 / 坠落两种打法的掉血 | 8.3 / 8.4 | 8.0 / 8.5 | 差距越小越好 |

两种打法的掉血差不到 1 点，说明在混合牌组里「保持清醒」和「主动坠落」都是可行的路线，坠落并不是稳亏。

### 7.4 遗留问题（阶段 3 补全内容后再调）

- **中期牌组打困难池偏快**（B、C 约 3.5 回合，目标 4–6）。单纯加敌人血量会让掉血超标，需要「加血 + 降伤害」一起调，属于敌人内容调整
- **遭遇 3 里堕落牌组掉血 10.6**，略超目标。这正是「嗅到疯狂」想要的惩罚效果，先保留，等精英和遗物加入后再看
- **混合组入癫 19%、守夜清明 44%**，都略低于目标；AI 的坠落判断比真人保守，需要纸面试玩确认
- AI 是一步贪心，只适合做相对比较；改动前后的差值比绝对值可靠
