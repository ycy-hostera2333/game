# 03 卡牌设计

## 1. 角色：调查员

| 属性 | 值 |
|---|---|
| 最大生命 | 70 |
| 理智上限 | 10 |
| 初始金币 | 99 |
| 起始遗物 | **调查笔记**：每场战斗首次进入癫狂时，获得 1 能量并抽 2 张牌（在敌人回合触发时，能量留到下回合） |
| 起始牌组（10 张） | 打击 ×5、防御 ×3、祷告 ×1、禁忌一瞥 ×1（模拟调参后用祷告换掉 1 张防御，让早期有理智回复，避免一进困难池就崩溃） |

起始遗物和「禁忌一瞥」的作用是第一场战斗就把玩家往理智机制上引：打出一瞥会失去理智，第一次掉进癫狂还有奖励，但守夜流可以选择不打。

| 传染 | 8 | 恐惧控制，桥梁流派 |

## 4. 关键组合（设计时要守住的「爽点」）

| 组合 | 机制 | 风险控制 |
|---|---|---|
| 圣痕 + 镇定 / 祷告 / 心灵之锚 | 满理智时恢复 → 溢出 → 全体伤害 | 恢复牌要么消耗要么数值低；侵蚀迫使守夜流先补回满 |
| 旧日注视 + 双面牌 | 清醒时也用癫狂面，不用掉理智 | 3 费启动慢；癫狂面的代价照样要付 |
| 疯狂本能 + 终末仪式 / 坠落 | 主动掉理智顺便打伤害 | 很快逼近崩溃；敌人、侵蚀、疯语削的理智不触发（[07 §8.5](07_数值框架.md)） |
| 恐惧之源 + 心智崩塌 | 恐惧持续堆叠，再一次性兑现 | 兑现后恐惧清零，震慑也会清零：玩家要在「控场」和「爆发」之间取舍，同一份恐惧只能兑现一次 |
| 群体癔症（堕落 × 传染） | 已缺失的理智转化成全体恐惧 | 一次性（消耗） |

## 5. 新卡设计检查清单

新增或修改一张卡之前，逐项确认：

1. 它推动或奖励哪个理智方向？（守夜 / 堕落 / 传染 / 中立）如果答不上来，说明它只是数值牌，这类牌占比控制在 30% 以下
2. 双面牌：癫狂面收益是清醒面的 1.6–1.8 倍，**而且**有明确的副作用
3. 效率落在 [07](07_数值框架.md) 给出的稀有度区间里
4. 卡面文字不超过 3 行，只用关键词表里已有的词
5. 有没有和已有的牌形成无限循环或零成本循环（重点检查：0 费 + 抽牌 + 能量的组合）
6. 升级的变化只改一个维度（数值 / 费用 / 关键词）
