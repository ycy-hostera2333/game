# 01 核心机制

## 1. 差异化方案对比

杀戮尖塔的骨架（能量 / 抽牌 / 格挡 / 意图 / 爬塔地图）原样保留，这套骨架已经被验证过，没必要重造。差异化集中在**一个**能贯穿战斗、构筑、地图三层的核心机制上。

| | 方案 A：理智与双面牌 | 方案 B：不可名状的意图 | 方案 C：腐化变异 |
|---|---|---|---|
| 一句话 | 理智是第二资源。跌破阈值后，双面牌翻到更强、带副作用的癫狂面 | 敌人意图默认部分隐藏，花「洞察」揭示 | 卡牌在跑局中被侵蚀，获得正负混合的变异词条 |
| 带来的决策 | 何时坠落、坠多深、要不要冒崩溃的风险；同一张牌在不同状态下价值不同 | 信息值不值得买 | 要不要接受变异，以及牌组朝哪个方向「异化」 |
| 和题材的契合 | ★★★ 克苏鲁的核心母题就是「直视真相的代价」 | ★★★ 未知恐惧 | ★★ 侵蚀 / 异化 |
| 实现成本 | 中：一个状态机 + 卡面刷新 | 低 | 高：词条组合爆炸，平衡和 UI 都贵 |
| 主要风险 | 双面信息量大；数值要平衡两份 | 尖塔的乐趣来自完全信息下求最优解，藏信息容易变成挫败感 | 随机性太强，局与局的手感会失控 |

### 结论

- **主机制采用 A**。
- **B 降级为 A 的子机制**：只在玩家**癫狂**时模糊意图数值（类型照常显示），另外由一个精英「无面修女」专门体现。这样「看不清」就成了玩家自己选择的代价，不是系统强加的惩罚。
- **C 放进想法池**，Demo 之后可以和 A 叠加（比如变异词条 = 永久带上癫狂代价）。

## 2. 理智系统规则（主机制）

### 2.1 基本参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| 理智上限 | 10 | 局内永久属性，事件 / 遗物 / 篝火可以增减 |
| 战斗开始时理智 | = 上限 | 每场战斗重置 |
| 癫狂线 | 理智 ≤ 4 | 低于等于此值即处于**癫狂**状态 |
| 清明 | 理智 ≥ 上限 − 1（上限 10 时为 9、10） | 卡牌和遗物的触发条件。原定「必须满理智」，试玩和模拟都显示守夜流几乎维持不住，放宽 1 点（见 [07 §7.5](07_数值框架.md)） |
| 崩溃 | 理智降至 0 | 立即结算崩溃（见 2.4） |

> 所有参数集中写在一张配置表里，纸面原型阶段优先调这几个数。

### 2.2 状态机

```
            理智 ≥ 上限−1
   ┌──────────[清明]──────────┐   （清明是「清醒」的子条件，不是独立状态）
   │                          │
[清醒] 理智 5..上限  ──理智≤4──▶  [癫狂] 理智 1..4  ──理智=0──▶ [崩溃结算] ──▶ 理智=3，回到[癫狂]
       ◀──理智≥5─────────────
```

进入或离开癫狂时触发 `OnLunacyChanged` 事件：
1. 所有牌堆里的**双面牌**刷新卡面（手牌播放翻面动画）
2. 敌人意图切换到模糊或清晰显示
3. 触发相关遗物 / 能力（如起始遗物「调查笔记」）

### 2.3 理智的来源与去向

| 降低理智 | 恢复理智 |
|---|---|
| 卡牌**代价N**（打出时失去 N 理智，理智不够也能打，结果是崩溃） | 卡牌（祷告、镇定、默祷……） |
| 敌人**精神攻击**（无视格挡） | 遗物（破旧祈祷书……） |
| 诅咒「疯语」（回合结束时还在手里：−1） | 药水「嗅盐」 |
| **侵蚀**：战斗第 4 回合起，每回合开始 −1 | 能力「心灵之锚」 |
| Boss / 精英的被动光环 | **没有自然回复** |

- **恢复量**按牌面数值计，包括溢出部分。实际理智不会超过上限，**溢出量** = 牌面恢复量 − 实际增加量（「圣痕」依赖这个值）。
- **心防**：每层抵消一次**来自敌人**的理智损失（精神攻击、光环）。自己打出的代价、侵蚀、疯语都不受心防影响，防止守夜流用心防免费打代价牌。

### 2.4 崩溃

理智降到 0 时立即依次执行：
1. 失去 **10% 最大生命**（向下取整；最大生命 70 时为 7）
2. 将 1 张「**疯语**」**永久**加入牌组，同时在本场的弃牌堆里放一张
3. 理智设为 **3**（仍处于癫狂）

设计意图：崩溃不会直接输掉一局，但会**在局层面留下伤痕**。堕落流的最优打法是在 1–2 理智的边缘游走，而不是无脑归零。

### 2.5 侵蚀（全局时钟）

战斗第 4 回合起，每回合开始时失去 1 理智。

- 防拖延：守夜流不能靠满理智无限磨血，必须投入资源去维持
- 给堕落流一个免费的下行通道
- 把题材落到机制上：「凝视得越久，失去的越多」
- 参数（起始回合、每回合损失量）可调；Boss 第二阶段会加速

### 2.6 双面牌

- 约 **25–30%** 的卡牌是双面牌（Demo 共 11 张）
- 清醒时用**清醒面**，癫狂时用**癫狂面**
- **打出时锁定**：用哪一面，按打出这张牌、支付代价**之前**的理智决定，结算过程中不再改变（完整时序见 [02 §3.5](02_战斗系统.md)）
- 癫狂面收益约为清醒面的 **1.6–1.8 倍**，并附带副作用：自伤、额外代价、弃牌、本身就消耗等（详见 [07](07_数值框架.md)）
- UI 要求：悬停时并排预览另一面；卡框按当前面切换配色；翻面时播放扭曲动画

### 2.7 癫狂的信息代价

- 癫狂时，敌人意图**只显示类型图标**（攻击 / 防御 / 增益 / 减益 / 精神攻击 / 召唤），**隐藏数值和段数**
- **不显示错误信息**：UI 不对玩家撒谎，只是遮住一部分信息
- 对冲手段：卡牌「点亮提灯」（本回合看清）、遗物「鲸油灯」（永久看清）

### 2.8 敌人对理智的反应

理智不只是玩家自己的事。敌人设计必须**双向施压**，防止某一个方向成为唯一解：

| 推玩家往下（克制守夜） | 惩罚癫狂（克制堕落） |
|---|---|
| 呓语者、腐鸦群（精神攻击） | 失魂镇民「嗅到疯狂」：你癫狂时，它的攻击 +4 |
| 灯塔守望者（每回合 −1 理智光环） | 网缚渔夫（塞状态牌，堵住堕落流的过牌） |
| Boss 第二阶段「深海之歌」 | 崩溃本身的局层代价 |

## 3. 三流派如何从理智规则里长出来

| 流派 | 目标状态 | 核心手段 | 收益点 | 主要威胁 |
|---|---|---|---|---|
| **守夜** | 保持清明（理智 ≥ 9） | 恢复理智、心防、格挡 | 「清明：」附加效果；按当前理智算伤害（明理之刃）；溢出伤害（圣痕） | 精神攻击、侵蚀，以及恢复手段被抽干 |
| **堕落** | 尽快跌入癫狂，在 1–2 理智边缘游走 | 代价牌、双面牌 | 癫狂面爆发；按缺失理智加伤害；每失去理智就造成伤害 | 崩溃、自伤累积、看不清意图 |
| **传染** | 不限（混合流） | 对敌人施加**恐惧**，把它们震慑掉 | 跳过敌人的行动；按恐惧层数造成伤害 | 无心智敌人（免疫）；精英 / Boss 意志高 |

传染流是**桥梁流派**：它的部分双面牌在癫狂面施加的恐惧翻倍，「群体癔症」又按已缺失的理智施加恐惧，所以它能和守夜、堕落中的任何一个混搭。
