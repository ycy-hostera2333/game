# 《深潮》策划案 · Demo 版

> 工作名暂定　|　类型：卡牌构筑 Roguelike（类杀戮尖塔）　|　题材：暗黑奇幻 / 克苏鲁　|　引擎：Unity 6.3 LTS（C#）　|　阶段目标：可玩 Demo

## 一句话定位

以**理智**作为第二资源的克苏鲁卡牌肉鸽：**离疯狂越近，你越强，也越看不清真相。**

## 设计支柱

1. **疯狂是力量，也是代价**：理智跌破阈值后，双面牌翻到更强的「癫狂面」，代价是副作用、敌人意图数值被模糊，理智归零会崩溃，并且牌组会被永久污染。
2. **信息就是生存**：保持清醒，换来完整信息和稳定收益；放弃清醒，换来爆发。每回合要想的不只是「怎么出牌」，还有「要不要坠落、坠多深」。
3. **一套规则，三条路**：守夜（维持满理智）、堕落（主动跌入癫狂）、传染（把恐惧施加给敌人）三个流派都从同一条理智规则里长出来，不是三套互不相干的系统。

## 世界观（简）

煤气灯时代的海港「灰潮镇」。调查员收到失踪导师的最后一封信，坐大潮那天的末班船赶到镇上，才发现全镇都在为潮水下的某物举行祭仪。

这一夜被导师用「逆潮」折了起来：调查员每死一次，钟响七下，就回到下船的栈桥。只有在同一夜里走到底，天才会亮（[12](12_叙事与世界观.md)）。

- **Demo**：第一幕「灰潮镇」，终点 Boss「溺亡司祭」
- **完整版规划**：灰潮镇 → 地下圣所 → 深海之门（三幕）
